## 文件约定

日报文件统一使用 `YYYY-MM-DD.md`，标题统一使用“GitHub 技术研读日报｜YYYY-MM-DD”。同一天重复整理时更新同一个文件：先校正状态和事实，再补充新的技术证据，同时保留仍然有效的分析、假设与实验记录。

新日报从 [TEMPLATE.md](TEMPLATE.md) 开始，正文保持“先结论、后机制”，按 IVM、优化器、执行与存储组织；每项至少说明原始 PR、变化、正确性边界、测试或性能证据、跨系统适用条件、待验证假设和阅读优先级。延伸分析从公开事实出发，按数据库与查询引擎的可迁移设计问题组织；无法从公开页面核实的内容要标注截止时间和证据缺口。
