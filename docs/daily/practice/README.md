# 每日练习

题目放 `questions/`，作答后或明确索要时的解答放 `answers/`，原始反馈与执行证据放
Git 忽略的 `.local/engineering-daily/`。当前待练：[JVM 对象发布](questions/jvm-publication-01.md)。

默认轮换：周一 C++、周二 Java/JVM、周三 Linux、周四系统设计、周五算法、
周六综合排障、周日复习。主线需要或旧题积压时允许调整，日报说明理由。
每期仅一道新题；课程的验证步骤是理解检查，不再塞入另一套面试作业。

每题记录稳定 `id` 与 `skill_key`、难度、15–25分钟预算、契约、边界用例、交付要求。
同能力14天内默认不出新的换皮题；进阶变式要说明新约束，复习题要链接旧题。
批改区分：没有作答、答错、部分理解、在已测范围内正确、具备后续掌握证据。

用户作答后再给分级提示、参考解、正确性证明、复杂度、测试和工程取舍。
若答题者仍想自己尝试，只给当前需要的提示，不强行展开完整解。
复习按作答锚点的1/3/7/14天执行，错题重新起算，不按题目发行日期起算。
