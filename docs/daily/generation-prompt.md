# 日报任务的生成指令

以下指令可以交给已有日报任务使用；本文件不会创建或修改定时任务。

> 在 xlab 仓库按 docs/skills/engineering-daily/SKILL.md 生成今天的工程研读日报。
> 日期和复习日期使用 Asia/Shanghai。先读取 docs/daily/AGENTS.md、发行历史、当前
> 主线路线图与本地反馈；运行 history、plan。用本地 Highway/SIMDe/JDK/Linux
> 固定 commit 的源码解释每天一个知识单元，按照真实反馈决定推进或复习。
> 将已有 GitHub 日报、公开技术阅读汇总与官方动态作为候选输入，按事件身份和
> 状态/技术增量去重；没有重要变化少写，获取失败标明未核实。Java 与 C++ 的提案、
> 实现、发布阶段分开。只发一道新题及一道到期回忆，参考解等作答后独立生成。
> 输出 docs/daily/YYYY-MM-DD.md、对应课程/题目与 editions/YYYY-MM-DD.json，
> 同日更新原文件。运行 check 并人工审查语义重复、证据与边界；没有硬件实测就明确
> 只做源码/代码生成分析。最后在聊天中给核心摘要、题目摘要与阅读链接。
> 不把已生成当成已读/已实践/已掌握，私人反馈和运行数据只留在 Git 忽略目录。
