## 引言：为什么电磁学是工程师最重要的物理学

Vol.I 建立了力学的世界观：粒子、力、守恒律。Vol.II 进入另一个维度：**场（Field）**。

场是空间中每一点都有定义的物理量。引力场、电场、磁场——这些"弥漫在空间中的实体"，是比粒子更基本的物理概念。

**工程师为什么必须理解电磁场**：

- CPU 的每个晶体管开关，是电场驱动的量子隧穿
- GPU 的 PCIe 总线，是电磁波在传输线中的传播
- Wi-Fi/5G，是麦克斯韦方程在天线和自由空间中的解
- 光互连（硅光子），是光子（电磁波量子）在波导中的传播
- MRI（核磁共振），是射频电磁场与量子自旋的相互作用

**电磁学是数字文明的物理基础**。不理解电磁场，就不能真正理解计算硬件的物理极限。

# Ch.1：电磁学——场的世界观

## 超距作用 vs 场的观点

牛顿引力的困扰：地球如何"知道"太阳在哪里？两个相距 1.5 亿公里的物体，如何瞬时相互作用？

**超距作用（Action at a Distance）**：牛顿的原始表述，两物体直接相互作用，无需中间媒介。

**场的观点（Field Theory）**：法拉第（Faraday）首先提出：每个电荷在周围空间产生一个**电场**，另一个电荷感受的是**本地**的电场——相互作用通过场传递，以有限速度（光速）传播。

场的观点彻底解决了超距作用的哲学困境，并预言了**电磁波**的存在——麦克斯韦方程预言电磁波以光速传播，1887 年赫兹实验验证，1895 年马可尼发明无线电。

**场是一个独立的物理实体**，有能量、有动量，在没有源（电荷、电流）的地方可以自由传播。

> **工程映射：消息队列的场论视角**
>
> 服务间通信有两种范式：
> - **同步 RPC（超距作用）**：调用者直接与被调用者交互，像牛顿引力——简单，但紧耦合，无法处理被调方不在线的情况
> - **异步消息队列（场论）**：发送方向队列（场）发布消息，接收方从队列（场）消费——解耦，消息在队列中"自主存在"，即使接收方暂时不在线消息也不丢失
>
> 电磁场从超距作用到场论的转变，对应于微服务架构从同步 RPC 到异步消息队列的演化——两者都是从"直接耦合"到"通过中间场传递"的范式转变，代价是引入了中间层（场/队列）的复杂性，收益是解耦和异步。

# Ch.2：矢量场的微分——▽ 算子

## 梯度、散度、旋度——三种微分

电磁学需要对三维矢量场做微分，有三种基本操作：

**梯度（Gradient）**：对标量场 $\phi$ 操作，给出矢量场：

$$\nabla\phi = \left(\frac{\partial\phi}{\partial x}, \frac{\partial\phi}{\partial y}, \frac{\partial\phi}{\partial z}\right)$$

物理意义：$\nabla\phi$ 指向 $\phi$ 增大最快的方向，大小是最大变化率。

**散度（Divergence）**：对矢量场 $\mathbf{F}$ 操作，给出标量场：

$$\nabla \cdot \mathbf{F} = \frac{\partial F_x}{\partial x} + \frac{\partial F_y}{\partial y} + \frac{\partial F_z}{\partial z}$$

物理意义：$\nabla\cdot\mathbf{F}$ 描述矢量场在某点的"源"（发散量）。若 $\nabla\cdot\mathbf{F} > 0$，该点是"源"；$< 0$，该点是"汇"。

**旋度（Curl）**：对矢量场 $\mathbf{F}$ 操作，给出矢量场：

$$\nabla \times \mathbf{F} = \left(\frac{\partial F_z}{\partial y} - \frac{\partial F_y}{\partial z}, \frac{\partial F_x}{\partial z} - \frac{\partial F_z}{\partial x}, \frac{\partial F_y}{\partial x} - \frac{\partial F_x}{\partial y}\right)$$

物理意义：$\nabla\times\mathbf{F}$ 描述矢量场在某点的"漩涡"（环流量）。旋度非零的场中有"旋转"。

**拉普拉斯算子**（散度的梯度）：

$$\nabla^2\phi = \nabla\cdot(\nabla\phi) = \frac{\partial^2\phi}{\partial x^2} + \frac{\partial^2\phi}{\partial y^2} + \frac{\partial^2\phi}{\partial z^2}$$

# Ch.3：矢量积分——高斯定理与斯托克斯定理

**高斯定理（Divergence Theorem）**：矢量场穿过封闭曲面的通量，等于曲面内散度的体积分：

$$\oint_S \mathbf{F} \cdot d\mathbf{A} = \int_V (\nabla\cdot\mathbf{F})\, dV$$

物理意义：穿出封闭面的净通量 = 内部源的总量。

**斯托克斯定理（Stokes' Theorem）**：矢量场沿封闭曲线的环流，等于曲线围成曲面上旋度的面积分：

$$\oint_C \mathbf{F} \cdot d\mathbf{l} = \int_S (\nabla\times\mathbf{F})\cdot d\mathbf{A}$$

物理意义：绕封闭环路的环流 = 面上旋度的积分（涡量的总量）。

**两大定理的统一性**：高斯定理和斯托克斯定理是**广义斯托克斯定理**（微分几何框架）的特例：

$$\int_M d\omega = \oint_{\partial M} \omega$$

微分形式 $\omega$ 在流形 $M$ 上的积分，等于其外微分 $d\omega$ 在边界 $\partial M$ 上的积分。这是现代数学中最深刻的定理之一，统一了微积分基本定理、高斯定理、斯托克斯定理和格林定理。

> **工程映射：守恒律的积分形式**
>
> 高斯定理是物理守恒律的数学基础。以电荷守恒为例：
>
> - 微分形式：$\frac{\partial\rho}{\partial t} + \nabla\cdot\mathbf{J} = 0$（连续性方程）
> - 积分形式（用高斯定理）：$\frac{dQ_V}{dt} = -\oint_S \mathbf{J}\cdot d\mathbf{A}$（区域内电荷变化 = 流出的电流）
>
> 这和分布式系统的**守恒量审计**完全对应：一个系统区域（体积）内的总账目变化，等于跨边界（封闭面）的净流量。分布式账本的余额守恒，是高斯定理在金融交易网络中的直接应用。

# Ch.4-5：静电学——库仑定律与高斯定律

## 电场的定义与叠加

点电荷 $q$ 产生的电场：

$$\mathbf{E} = \frac{q}{4\pi\epsilon_0} \frac{\hat{r}}{r^2}$$

**叠加原理**：多个电荷产生的总电场是各电荷场的矢量和（线性叠加）：

$$\mathbf{E}_{\text{total}} = \sum_i \mathbf{E}_i$$

## 高斯定律——电磁学的第一方程

$$\nabla\cdot\mathbf{E} = \frac{\rho}{\epsilon_0} \quad \Leftrightarrow \quad \oint_S \mathbf{E}\cdot d\mathbf{A} = \frac{Q_{\text{enc}}}{\epsilon_0}$$

**高斯定律**：电场的散度等于电荷密度除以 $\epsilon_0$；穿出封闭面的电通量等于面内总电荷除以 $\epsilon_0$。

**高斯定律的强大**：对于有对称性的电荷分布（球对称、柱对称、平面对称），无需积分，直接用高斯定律求电场：

**均匀带电球体外部**（$r > R$）：$E = Q/(4\pi\epsilon_0 r^2)$——与点电荷相同
**均匀带电无限长导线**：$E = \lambda/(2\pi\epsilon_0 r)$（$\lambda$ 是线电荷密度）
**均匀带电无限大平板**：$E = \sigma/(2\epsilon_0)$（$\sigma$ 是面电荷密度），与距离无关

**电势（Electric Potential）**：

$$\phi = -\int \mathbf{E}\cdot d\mathbf{l} \quad \Rightarrow \quad \mathbf{E} = -\nabla\phi$$

电场是电势的负梯度。电势满足**泊松方程（Poisson Equation）**：

$$\nabla^2\phi = -\frac{\rho}{\epsilon_0}$$

无源区域：$\nabla^2\phi = 0$（**拉普拉斯方程**）

# Ch.6：各种情况下的电场

## 导体的静电性质

静电平衡时，导体有三个重要性质：

1. **内部电场为零**（$\mathbf{E} = 0$ in conductor）：任何内部电场都会驱动电荷运动，直到平衡
2. **所有多余电荷在表面**：内部无净电荷，$\nabla\cdot\mathbf{E} = 0$
3. **表面是等势面**：$\mathbf{E}$ 垂直于导体表面

**法拉第笼（Faraday Cage）**：封闭的导体壳，内部电场为零，外部电场不能穿入。电子设备的金属外壳、机房的接地屏蔽层——都是法拉第笼原理的工程应用。

**电容器（Capacitor）**：两导体之间的电场存储能量：

$$C = \frac{Q}{V}, \quad U = \frac{1}{2}CV^2 = \frac{Q^2}{2C}$$

芯片中的 DRAM 存储单元，每个比特就是一个电容（存储电荷 = 1，不存储 = 0）。DRAM 的刷新（Refresh）是因为电容缓慢漏电（电荷泄漏），需要定期"补充"——这是静电物理在数字存储中的直接体现。

## 拉普拉斯方程的解——唯一性定理

**唯一性定理**：给定边界条件（边界上的电势值），拉普拉斯方程 $\nabla^2\phi = 0$ 的解唯一。

**物理含义**：静电问题完全由边界条件决定。边界内的场分布，是边界条件的唯一函数——"初始条件"和"边界条件"唯一决定场。

**方法论含义**：任何满足边界条件的解，不管用什么方法得到（猜测、查表、数值模拟），都是正确的唯一解。这就是为什么静电学中"镜像法"（Image Charge Method）是合法的——只要找到满足边界条件的解，不管用了什么"非正统"方法，答案一定正确。

> **工程类比：分布式系统的唯一性**
>
> 唯一性定理在工程中的对应：如果你能证明一个算法在给定约束（边界条件）下产生唯一解，那么任何满足约束的实现都是等价的——实现细节不影响结果。这是**接口与实现分离**的理论基础：只要实现满足接口约束（边界条件），用户不需要关心内部如何实现（求解方法）。SQL 的标准就是这样：给定查询语义（边界条件），任何产生相同结果的执行计划（求解方法）都是等价的。
