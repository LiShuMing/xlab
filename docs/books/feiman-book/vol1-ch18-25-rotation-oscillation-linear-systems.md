# Ch.18-20：转动——角动量与刚体动力学

## 引言：旋转为什么特殊？

平动（Translation）和转动（Rotation）是经典力学的两类基本运动。平动已经由 $\mathbf{F} = m\mathbf{a}$ 完整描述。转动有其对应的方程，但有一些平动中没有的奇特现象——**进动（Precession）**、**章动（Nutation）**——让转动比平动复杂得多，也有趣得多。

## Part 1：转动动力学的基本方程

**力矩（Torque）**：

$$\boldsymbol{\tau} = \mathbf{r} \times \mathbf{F}$$

**角动量（Angular Momentum）**：

$$\mathbf{L} = \mathbf{r} \times \mathbf{p} = I\boldsymbol{\omega}$$

（对绕固定轴的刚体，$I$ 是转动惯量）

**转动定律**（对应 $\mathbf{F} = m\mathbf{a}$）：

$$\boldsymbol{\tau} = \frac{d\mathbf{L}}{dt}$$

**角动量守恒**（Noether 定理：空间旋转对称性）：当合力矩为零时，$\mathbf{L} = \text{const}$。

经典例子：花样滑冰运动员收手时旋转加速——角动量守恒，转动惯量 $I$ 减小（手臂靠近轴），角速度 $\omega$ 增大（$L = I\omega = \text{const}$）。

## Part 2：转动惯量——质量分布的几何效应

**转动惯量**（对绕轴 $z$ 的转动）：

$$I = \sum_i m_i r_i^2 = \int r^2 \, dm$$

几个典型值：
- 均匀细杆（绕端点）：$I = \frac{1}{3}ML^2$
- 均匀实心球：$I = \frac{2}{5}MR^2$
- 均匀细圆环（绕对称轴）：$I = MR^2$

**平行轴定理**：$I = I_{\text{cm}} + Md^2$（$d$ 是平行轴到质心轴的距离）

转动惯量是**质量的几何化**——不只看质量大小，还看质量的空间分布。质量越集中在旋转轴附近，$I$ 越小，越容易旋转；质量越分散在外侧，$I$ 越大，旋转越"笨重"。

> **系统工程映射**：转动惯量对应系统的**惯性（Inertia）**——修改起来的难度。一个代码库中，频繁被其他模块引用的核心接口（质量在外侧，类比大 $I$），修改的"阻力"大；一个内部实现模块（质量在轴心，小 $I$），修改容易。重构高 $I$ 模块需要更大的"力矩"（协调成本、测试覆盖、兼容性保证）。这就是软件架构中"接口稳定性"设计的物理直觉来源。

## Part 3：陀螺仪与进动——反直觉的角动量

**陀螺仪（Gyroscope）**的进动是角动量最反直觉的表现：

高速旋转的陀螺，一端支撑，理论上应该在重力作用下"倒下"。但实际上它绕支撑点做**进动（Precession）**——在水平面内缓慢旋转，不倒下。

原因：重力产生力矩 $\boldsymbol{\tau} = \mathbf{r} \times M\mathbf{g}$（水平方向），角动量的变化 $d\mathbf{L} = \boldsymbol{\tau} dt$ 垂直于 $\mathbf{L}$（不改变大小，只改变方向），使 $\mathbf{L}$ 缓慢转向——即进动。

$$\Omega_{\text{precession}} = \frac{MgR}{I\omega}$$

**应用**：惯性导航系统（Inertial Navigation System，INS）利用陀螺仪进动的精确可预测性，在无 GPS 条件下计算飞行器位置（战斗机、潜艇、导弹）。MEMS 陀螺仪（微机电系统）是智能手机姿态传感器的核心器件。

# Ch.21：谐振子——物理学中最重要的系统

## 引言：为什么谐振子如此重要？

简谐振动（Simple Harmonic Motion，SHM）是物理学中被研究得最透彻的系统，原因在 Ch.13-14 已经预告：**任何系统在稳定平衡点附近，都近似做简谐振动**。

理解谐振子，就理解了世界上所有系统在平衡附近的行为。

## Part 1：谐振子的运动方程

弹簧-质量系统（胡克定律）：

$$F = -kx \Rightarrow m\ddot{x} = -kx \Rightarrow \ddot{x} + \omega_0^2 x = 0$$

其中 $\omega_0 = \sqrt{k/m}$ 是**固有频率（Natural Frequency）**。

解：$x(t) = A\cos(\omega_0 t + \phi)$

**相图**（$x$-$\dot{x}$ 平面）：简谐振动对应椭圆轨迹——能量守恒（椭圆代表等能量面的相轨迹）。

## Part 2：阻尼振动

加入摩擦阻力（$F_{\text{damping}} = -b\dot{x}$）：

$$m\ddot{x} + b\dot{x} + kx = 0$$

定义品质因数 $Q = \omega_0 m/b$：

- **欠阻尼（$Q > 1/2$）**：振荡衰减，振幅指数衰减 $\propto e^{-\omega_0 t/2Q}$
- **临界阻尼（$Q = 1/2$）**：最快收敛到平衡，无振荡（机械减震器、弹簧缓冲的最优设计点）
- **过阻尼（$Q < 1/2$）**：缓慢单调恢复到平衡

$Q$ 越高，振动维持越久，系统"记忆"越长。

> **工程映射：PID 控制器的阻尼设计**
>
> PID（比例-积分-微分）控制器是工程中最广泛使用的反馈控制器。其物理本质是对被控系统加入阻尼，使系统稳定在设定点。
>
> - P（比例项）↔ 弹簧恢复力（$-kx$）
> - D（微分项）↔ 阻尼力（$-b\dot{x}$）
> - I（积分项）↔ 消除稳态误差
>
> PID 调参的核心是平衡三者：D 太小（欠阻尼），系统振荡不稳定；D 太大（过阻尼），响应太慢。临界阻尼是最优点——这就是为什么机械减震器、电力系统调速器、数据库连接池的 burst 控制都有类似的"最优阻尼"设计原则。

# Ch.22-25：代数、共振、瞬态与线性系统

## Ch.22：代数——复数是谐振子的自然语言

费曼在 Ch.22 专门介绍了**复数**，理由是：简谐振动的数学用复数描述最自然。

$$x(t) = \text{Re}[Ae^{i(\omega t + \phi)}] = \text{Re}[\hat{A} e^{i\omega t}]$$

其中 $\hat{A} = Ae^{i\phi}$ 是复振幅（包含振幅和相位信息）。

**复指数的力量**：$e^{i\omega t} = \cos\omega t + i\sin\omega t$（欧拉公式）

用复数描述振动，加法（叠加原理）变成复数加法，相位差变成复数的辐角，这让干涉、衍射、电路分析、滤波器设计都变得极其简洁。

**傅里叶分析的预告**：任意周期函数可以展开为正弦/余弦的叠加（傅里叶级数），任意信号可以展开为连续频谱（傅里叶变换）：

$$f(t) = \int_{-\infty}^{\infty} \hat{f}(\omega) e^{i\omega t} \frac{d\omega}{2\pi}, \quad \hat{f}(\omega) = \int_{-\infty}^{\infty} f(t) e^{-i\omega t} dt$$

傅里叶变换是时域（时间）和频域（频率）之间的**对偶变换**——时域的乘法对应频域的卷积，时域的微分对应频域的乘以 $i\omega$。这使得微分方程在频域中变成代数方程，极大简化了线性系统分析。

> **工程应用：FFT 是信号处理的核心**
>
> **快速傅里叶变换（FFT）**是 20 世纪最重要的算法之一（Cooley-Tukey，1965）。将 $N$ 点 DFT 的计算复杂度从 $O(N^2)$ 降到 $O(N\log N)$：
>
> - 音频压缩（MP3：用 MDCT，类似 FFT，在频域量化丢弃不重要频率成分）
> - 图像压缩（JPEG：DCT 是 FFT 的余弦版本）
> - 无线通信（OFDM：4G/5G 的调制方式，用 FFT 实现多载波传输）
> - 数值计算（快速多项式乘法、大数乘法）
>
> LLM 推理中，**线性注意力（Linear Attention）**的某些变体尝试用 FFT 加速 Attention 计算（从 $O(N^2)$ 到 $O(N\log N)$）——这是费曼谐振子数学在 2024 年 AI 架构优化中的直接应用。

## Ch.23：共振——系统在固有频率处的极度敏感

**强迫振动**：外部以频率 $\omega$ 施加驱动力 $F_0\cos\omega t$，系统的稳态响应：

$$x(t) = \frac{F_0/m}{\sqrt{(\omega_0^2-\omega^2)^2 + (\omega b/m)^2}} \cos(\omega t + \phi)$$

**共振（Resonance）**：当 $\omega \to \omega_0$ 时，振幅极大（低阻尼时趋于无穷）。

共振是系统对**特定频率输入的极度放大**。品质因数 $Q$ 描述共振峰的尖锐程度：频率选择性（带宽 $\Delta\omega = \omega_0/Q$）。

**共振的工程应用**：

- 无线电调谐（LC 电路的共振频率 $\omega_0 = 1/\sqrt{LC}$ 选择特定电台）
- 核磁共振（MRI：氢核在特定磁场中的共振频率用于医学成像）
- 激光（光在谐振腔中的受激发射共振，实现光放大）
- 石英振荡器（晶体的机械共振用作时钟基准，Ch.5）

**共振的危险性**：

塔科马海峡大桥（1940）在风的周期性涡旋力与桥的扭转固有频率共振下坍塌（严格说是颤振，非简单共振，但道理类似）。

> **系统工程中的"共振"**：
>
> 分布式系统有一种类似共振的现象：**惊群效应（Thundering Herd）**——大量并发请求同时到达，触发同时的缓存失效，同时打到数据库，数据库过载，导致更多超时，更多重试……系统陷入"共振"般的正反馈循环。
>
> **防共振设计**：对应于在系统中引入"阻尼"——请求抖动（Jitter）、指数退避（Exponential Backoff）、令牌桶限流——都是通过"去相关化"打破周期性同步，从而避免共振。Q 值越低（阻尼越大），系统对特定频率的输入越不敏感，越稳定，代价是响应变慢。

## Ch.24-25：瞬态响应与线性系统综述

**瞬态（Transient）**：系统从初始状态向稳态过渡的过程。对线性系统，瞬态是系统固有频率的自由振动（自由衰减），稳态是驱动频率的受迫振动。

**叠加原理**（线性系统的核心）：

$$\mathcal{L}[a f_1(t) + b f_2(t)] = a\mathcal{L}[f_1(t)] + b\mathcal{L}[f_2(t)]$$

线性系统的任意输入响应 = 对系统的**冲激响应**（Green 函数）做卷积：

$$y(t) = \int_{-\infty}^{t} h(t-\tau) x(\tau) d\tau = h * x$$

**这是线性系统理论最深刻的结论**：知道了冲激响应 $h(t)$，就知道了线性系统对任意输入的响应——系统的全部动力学信息压缩在 $h(t)$ 中。

在频域：$Y(\omega) = H(\omega) \cdot X(\omega)$（卷积变乘法）

$H(\omega)$ 是**传递函数（Transfer Function）**，是系统在频域的"签名"。

> **数据库的传递函数类比**
>
> 一个数据库系统的"传递函数"，是从查询输入到响应延迟输出的映射——它捕获了系统在不同频率（QPS）下的响应特性：低 QPS 时（低频输入），延迟稳定（稳态响应）；高 QPS 时（高频扰动），系统是否能快速响应（带宽）？是否会"共振"（惊群效应）？
>
> 数据库压测（Benchmark）本质上是在测量系统的传递函数——不同输入频率（并发度）下的输出（延迟、吞吐）。理解传递函数，比只看"峰值 QPS"深刻得多。

## 结语：振动、频率、共振——线性世界的统一主题

Ch.18-25 覆盖了经典力学的旋转与振动部分。这些章节表面上很不相同（陀螺仪、弹簧、电路、声波），但共享同一个数学骨架：**线性微分方程 + 正弦基函数 + 叠加原理**。

这个数学骨架的工程版本，是**频谱分析、滤波器设计、控制理论、信号处理**——20 世纪整个电气工程的数学基础。

在 AI 时代，它的新化身是：**Transformer 的频率视角**（最近的研究表明，Attention 机制可以被理解为动态滤波器，不同的 Attention Head 学习了不同频率的语言信号），以及**谱图神经网络（Spectral GNN）**——直接在图的频谱域（拉普拉斯特征值）上操作，是傅里叶分析在非欧空间的推广。

费曼在 1961 年讲授的谐振子，是 2024 年 AI 架构创新的数学根基之一。
