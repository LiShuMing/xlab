## 1. 2026-10-14 · 复杂度（原理）

### 今日：复杂度（原理）

**一句话：** 复杂度不关心「这台电脑跑了几毫秒」，而关心**基本操作次数随输入规模 \(n\) 怎么涨**——竞赛里通常看最坏情况。

**核心思想：**  
机器快慢差很多，加减乘除耗时也不一样，所以我们数「大约做了多少次基本操作」，再丢掉常数和低阶项，只留增长趋势。比如 \(100n\) 和 \(n^2\)：\(n\) 很小时后者可能更快，但 \(n\) 一大，平方项会把线性远远甩开。所以赛场上更在乎「\(n\) 变大还能不能过」。

常用记号（记个印象就够）：
- \(O(g(n))\)：上界，「不会比这涨得更快」（赛场最常用）
- \(\Theta(g(n))\)：紧的同阶上下界
- \(\Omega(g(n))\)：下界

实用法则：求和取较大的那个阶；相乘则阶相乘；对数换底只差常数，写作 \(\log n\) 即可。

**怎么做（看循环一眼估复杂度）：**

```cpp
for (int i = 0; i < n; ++i)
  for (int j = 0; j < n; ++j)
    for (int k = 0; k < m; ++k)
      /* 常数次操作 */;
```

三层分别跑 \(n,n,m\) 次 → \(\Theta(n^2 m)\)。  
邻接表 DFS 连通图：每个点、每条边访问常数次 → \(\Theta(n+m)\)。

注意：和输入规模无关的量当常数。`for (i=0;i<100000;++i)` 若 100000 不是输入，复杂度是 \(O(1)\)；但「预先打表覆盖所有可能输入」并不能把任意规模问题变成 \(O(1)\)——理论假设算法要对任意大的 \(n\) 成立。

递归式 \(T(n)=aT(n/b)+f(n)\) 可用**主定理**对照三种情况（合并代价相对子问题规模谁大谁小）；今天先知道有这工具，后面讲分治排序时再用。

**坑：**  
- 把「某组小数据测得快」当成复杂度好  
- 混用最坏 / 平均（竞赛默认按最坏估时限）  
- 把固定数组长度误当成 \(n\)

原文：[复杂度简介 - OI Wiki](https://oi-wiki.org/basic/complexity/)

## 2. 2026-10-14 · 二分（算法）

### 今日：二分（算法）

**一句话：** 在有序数组里找元素只是基础用法；竞赛里真正常用的是答案具有单调性时的「二分答案」，还要配好边界模板，以及用三分求单峰函数的极值。

**核心思想**

把「求满足条件 \(P\) 的最大或最小 \(x\)」变成一个反复问的问题：`check(mid)` 行不行。只要「\(x\) 是否满足 \(P\)」随 \(x\) 单调变化（形如 `00…011…1` 或 `11…100…0`），每问一次就能把答案区间砍掉一半。

举个例子（砍树）：树高 \(20,15,10,17\)，至少要砍到 \(M=7\) 米木头。锯片高度 \(H\) 越高，能砍到的木头越少。`check(H)` 判断 \(\sum\max(0,a_i-H)\ge M\) 是否成立，然后二分出最大的可行 \(H\)。\(H=15\) 时刚好得到 7 米，再高就不够了。

**怎么做**

求最小可行值（`00…011…1`），用闭区间写法，循环过程中答案始终留在区间里：

```cpp
int binary_search_min(int L, int R) {
  int l = L, r = R;
  while (l < r) {
    int mid = l + ((r - l) >> 1);  // 防溢出
    if (check(mid)) r = mid;
    else l = mid + 1;
  }
  return check(l) ? l : -1;  // 无解要再判一次
}
```

求最大可行值（比如砍树），用两侧哨兵的写法：

```cpp
int l = 0, r = 1e9 + 1;  // 约定 check(l) 为真、check(r) 为假
while (l + 1 < r) {
  int mid = (l + r) / 2;
  if (check(mid)) l = mid;
  else r = mid;
}
return l;
```

- **浮点二分：** 不要写 `mid±1`，边界直接赋成 `mid`。固定迭代 100 次左右，比写 `while (r-l>eps)` 更稳。
- **三分求单峰极值：** 取两个点 `lmid` 和 `rmid`，若 `f(lmid)<f(rmid)` 就丢掉左边一段，否则丢掉右边一段（例题洛谷 P3382）。
- **STL：** 用 `lower_bound` 和 `upper_bound` 之前，序列必须已经有序。对 `set` 和 `map` 要用它们自带的成员函数 `lower_bound`，用全局版本会退化成 \(O(n)\)。

**复杂度与坑**

- 总复杂度是 \(O(M\log\frac{R-L}{\varepsilon})\)，其中 \(M\) 是做一次 `check` 的代价。
- `(l+r)>>1` 可能溢出，改写成 `l+((r-l)>>1)`。另外负数右移一位和除以 2 结果不同，可能导致死循环。
- 循环条件、边界和更新规则必须配套：`l<r` 配 `r=mid`，`l<=r` 配 `r=mid-1`，混着用就会出错。
- `eps` 设得太小，浮点误差可能让循环停不下来；范围很大时改用固定迭代次数。

原文：[二分 - OI Wiki](https://oi-wiki.org/basic/binary/)

## 3. 2026-10-16 · 倍增（Binary Lifting）｜算法

**📘 每日 OI Wiki · 倍增（Binary Lifting）｜算法**

**一句话用途：** 状态要「走 m 步」、m 又大到没法逐步模拟（比如 10^18）时，只预处理走 \(2^i\) 步的结果，查询时按 m 的二进制位拼起来，总共 \(O(\log m)\) 步就到。

**核心思想**

原文开头用砝码打比方：用 1、2、4、8、16 这五个砝码，就能称出 \([0,31]\) 里的任何重量；范围翻一倍，只要多加一个砝码。倍增也是这个道理，前提是问题能拆分：走 \(2^i\) 步，等于先走 \(2^{i-1}\) 步，再从落点接着走 \(2^{i-1}\) 步。

**例题（原文题二）：** 一个长度为 \(n\) 的环，每次从 \(i\) 跳到 \((i+k)\bmod n+1\)，一共跳 \(m\le 10^{18}\) 次，求每次跳跃起点的权值之和（模 \(10^9+7\)）。

- `go[i][x]`：从 \(x\) 跳 \(2^i\) 步之后到的点
- `sum[i][x]`：这 \(2^i\) 步途中经过的点权和

转移就两行：

```cpp
go[i][x]  = go[i-1][ go[i-1][x] ];
sum[i][x] = sum[i-1][x] + sum[i-1][ go[i-1][x] ];
```

比如要跳 13 步，13 的二进制是 1101，就依次跳 1、4、8 步，每跳一段把这段的 `sum` 累加上去。

**关键细节：sum 按左闭右开算。** `sum` 里只算起点、不算终点（跳 1 步只记 \(a_x\) 自己）。这样两段拼接的时候，前一段的终点就是后一段的起点，只会算一次，不重不漏。这是倍增维护「路径信息」时最常见的坑。

**怎么做（模板，按原文参考代码整理）**

```cpp
const int LOG = 60;            // m ≤ 1e18，开 0..59 层就够
int go[LOG][N], sum[LOG][N];   // 层数这一维放前面，cache 更友好

for (int x = 1; x <= n; ++x) { go[0][x] = (x + k) % n + 1; sum[0][x] = a[x]; }
for (int i = 1; i < LOG; ++i)
  for (int x = 1; x <= n; ++x) {
    go[i][x]  = go[i-1][go[i-1][x]];
    sum[i][x] = (sum[i-1][x] + sum[i-1][go[i-1][x]]) % MOD;
  }

int ans = 0, cur = 1;
for (int i = 0; m; ++i)
  if (m >> i & 1) {
    ans = (ans + sum[i][cur]) % MOD;
    cur = go[i][cur];
    m ^= 1LL << i;
  }
```

**树上的用法：倍增求 LCA（最近公共祖先，原文让去看 LCA 页，这里一起讲）**

`fa[i][x]` 表示 \(x\) 的第 \(2^i\) 个祖先，DFS 时按 `fa[i][x] = fa[i-1][fa[i-1][x]]` 递推出来。查询分两步：

1. **先跳到同一深度：** 把深度差 \(y\) 按二进制拆开，深的那个点按 \(y\) 的每个 1 位往上跳。
2. **再一起往上跳：** \(i\) 从大往小试，**只有 `fa[i][u] != fa[i][v]` 时才跳**。最后答案是 `fa[0][u]`。

```cpp
int lca(int u, int v) {
  if (dep[u] < dep[v]) swap(u, v);
  for (int i = LOG - 1; i >= 0; --i)
    if (dep[u] - (1 << i) >= dep[v]) u = fa[i][u];
  if (u == v) return u;               // 一个点本来就是另一个的祖先
  for (int i = LOG - 1; i >= 0; --i)
    if (fa[i][u] != fa[i][v]) u = fa[i][u], v = fa[i][v];
  return fa[0][u];
}
```

为什么第二步要用「不相等才跳」？因为「相等」只说明跳到了某个公共祖先，不一定是最近的那个；「不相等」是单调可判的，跳到最后一定停在 LCA 正下方的两个儿子上。跳过根时，祖先统一设成 0（或者根自己），这样不会越界。

求树上距离可以套原文的性质 7：\(d(u,v)=h(u)+h(v)-2h(\text{LCA}(u,v))\)，其中 \(h\) 是点到根的距离（例题 HDU 2586）。如果要的是路径最大边、路径和这类信息，就像环形题的 `sum` 一样，再开一个 `mx[i][x]`，跳的时候一起合并。

**复杂度与坑**

- 预处理 \(\Theta(n\log m)\)，每次查询 \(\Theta(\log m)\)；LCA 是 \(O(n\log n)\) 预处理，\(O(\log n)\) 查询。
- 空间也是 \(n\log m\)：\(n=10^6\)、60 层时两个 int 表大约 480MB。原文就是这么开的，实际比赛先看清内存限制。
- 层数要盖住 m 的最高位：\(10^{18}<2^{60}\)，所以开 60 层；移位一定写 `1LL << i`。
- 小的那一维（层数）放在前面，能减少 cache miss，原文专门提了这一点。
- 路径信息按左闭右开定义，免得把拼接点算两次。
- LCA 第二步必须**从大到小**枚举，第一步跳完别忘了特判 `u == v`。
- 倍增的另一个经典应用是 RMQ（区间最值查询），也就是后面要讲的 ST 表，原理和这里完全一样。

**原文链接：** [OI Wiki 倍增](https://oi-wiki.org/basic/binary-lifting/)，以及 [OI Wiki 最近公共祖先](https://oi-wiki.org/graph/lca/)

## 4. 2026-10-17 · 并查集（数据结构）

**今日 OI Wiki：并查集（数据结构）**

**一句话用途：** 动态维护「谁和谁在同一个集合里」，支持合并、判同集。稍作改造还能维护元素之间的相对关系（带权），或者支持删除和移动单个元素。

**核心思想**
每个集合存成一棵树，根节点代表整个集合，`find(x)` 沿父指针往上走到根。有两个优化：
- **路径压缩：** 查询途中经过的每个点都直接挂到根上。
- **启发式合并：** 把小树（按点数或深度比）挂到大树下面。

两个一起用，单次操作均摊 \( O(\alpha(n)) \)，可以看成常数。只用路径压缩，最坏是 \( O(m\log n) \)（Tarjan 证明，不过平均情况仍是 \( O(m\alpha(m,n)) \)，姚期智证明）；只用启发式合并是 \( O(m\log n) \)。

**基础模板（路径压缩加按大小合并）**
```cpp
struct DSU {
  vector<int> pa, sz;
  DSU(int n) : pa(n), sz(n, 1) { iota(pa.begin(), pa.end(), 0); }
  int find(int x) { return pa[x] == x ? x : pa[x] = find(pa[x]); }
  bool unite(int x, int y) {
    x = find(x), y = find(y);
    if (x == y) return false;
    if (sz[x] < sz[y]) swap(x, y);
    pa[y] = x; sz[x] += sz[y];
    return true;
  }
};
```

**变形一：带权并查集（重点）**
边权下放到子节点存，`d[x]` 表示 x 相对父亲的「势能差」，路径压缩之后就变成相对根的差。约定 `unite(x, y, w)` 表示声明 \( d_y - d_x = w \)。
```cpp
int find(int x) {
  if (pa[x] == x) return x;
  int r = find(pa[x]);
  d[x] = (d[x] + d[pa[x]]) % M;  // 先递归，此时 d[pa[x]] 已是父亲到根的差
  return pa[x] = r;
}
bool unite(int x, int y, int w) {
  int rx = find(x), ry = find(y);
  w = ((w + d[x] - d[y]) % M + M) % M;  // 换算成 d[ry] - d[rx] 应有的值
  if (rx == ry) return w == 0;          // 已连通：检查是否矛盾
  if (sz[rx] < sz[ry]) swap(rx, ry), w = (M - w) % M;  // 反着挂，权值取反
  pa[ry] = rx; sz[rx] += sz[ry]; d[ry] = w;
  return true;
}
// 查询 x 和 y 的差：同根时就是 d[y] - d[x]
```
推导关键：合并后 y 相对 rx 的势能是 \( d_y + d_{ry} \)，要让它减去 \( d_x \) 等于 w，所以 \( d_{ry} = w + d_x - d_y \)。

经典例题是 **NOI2001 食物链**：模 3 下，同类就是差 0，x 吃 y 就是 \( d_y - d_x \equiv 1 \)。一句话是假话，当且仅当两点已经连通、而且差值和这句话说的矛盾（再加上编号越界这类显然情况）。

**变形二：种类并查集（扩展域）**
模数很小的时候，可以把一个点拆成多个状态。食物链里拆成 x、x+n、x+2n，分别表示「和 x 同类」「被 x 吃」「吃 x」。比如说 `1 x y` 是假话，当且仅当 y 已经和 x+n 或 x+2n 在同一集合。

ABC396E（\( A_x \oplus A_y = Z \)，求总和最小的解）也是这个思路：按二进制位拆开，每一位都是「相同或不同」的关系，用带权或种类并查集维护。每个连通块会分成两组取值相反，让人数多的那组取 0。

**变形三：带删除和移动（虚点技巧）**
普通并查集删掉一个点，会把挂在它下面的子树一起带走。解决办法是一开始给每个元素 i 建一个虚点，让 i 指向它；合并永远是根连根，所以只有虚点会有孩子，真实元素始终是叶子。
- 删除 x：所在集合的 size 减一，再给 x 新开一个虚点当父亲（`pa[x] = id++`）。
- 移动 x 到 y 所在集合：原集合的 size 和 sum 减掉 x，再把 x 直接挂到 y 的根上（UVa11987 Almost Union-Find）。

**复杂度与坑**
- 并查集**不能低成本分裂集合**。
- 可持久化并查集、线段树分治加并查集这类场景，要**只用启发式合并、不用路径压缩**，因为路径压缩一次会改很多指针，没法撤销或持久化。
- 带权 find 里一定要先递归、再累加权值、最后改父指针，顺序错了，权值就是旧父亲的。
- 模意义下做减法记得 `+M` 再取模；swap 根时，权值也要取反。
- 只用路径压缩的递归 find，碰上长链可能爆栈，点数到百万级时可以加上按大小合并或者改成迭代写法。

**练习：** NOI2015 程序自动分析、JSOI2008 星球大战（倒序加边）、NOI2002 银河英雄传说（带权）、NOIP2023 三值逻辑。Kruskal 和 Tarjan 离线求 LCA 也都是基于并查集。

原文：[OI Wiki 并查集](https://oi-wiki.org/ds/dsu/)

## 5. 2026-10-18 · 堆简介与二叉堆（数据结构）

**堆简介与二叉堆**（数据结构）

一句话用途：O(log n) 维护最值；手写堆看清上下调，对顶堆不用权值线段树就能动态第 k 大 / 滑动中位数。

**核心思想**

完全二叉树用数组下标：根是 1，`i` 的儿子是 `2i`、`2i+1`。大根堆：父 ≥ 子，根就是最大。

插入：放到末尾再 **向上调整**；删根：末尾换到根再 **向下调整**。小例子：大根堆 `[7,5,6,3]` 插 8 → 先变成 `[7,5,6,3,8]`，8 和 5 换、再和 7 换 → `[8,7,6,3,5]`。

建堆别一个个插（Θ(n log n)）。从约 `n/2` 往下扫 `down`，等价于合并两个已合法的子堆，主定理给出 **Θ(n)**——堆性质弱，排列不唯一，所以能线性建。

**怎么做（关键模板）**

```cpp
void up(int x) {
  while (x > 1 && h[x] > h[x / 2]) {
    swap(h[x], h[x / 2]);
    x /= 2;
  }
}
void down(int x) {
  while (x * 2 <= n) {
    int t = x * 2;
    if (t + 1 <= n && h[t + 1] > h[t]) ++t;  // 选更大儿子
    if (h[t] <= h[x]) break;
    swap(h[x], h[t]);
    x = t;
  }
}
void build() { for (int i = n / 2; i >= 1; --i) down(i); }  // Θ(n)
```

**对顶堆**（动态第 k 大 / 中位数）：小根堆存「前 k 大」（含第 k），大根堆存更小的那一半。插入按与小根堆顶比较分流，再把两边大小调到 `|小根|=k`；查第 k 大就是小根堆顶，O(1)。中位数时令 `k = (n+1)/2`（偶数取较小者）即可。`priority_queue` 够用，不必手写二叉堆。

**复杂度与坑**
- 单次 up / down / push / pop：O(log n)；线性建堆 Θ(n)。
- `down` 必须先比两个儿子再和自己比，漏右儿子会破坏堆性质。
- 下标从 1 起；`priority_queue` 默认大根堆，小根堆用 `greater<>`。
- 对顶堆维护后两边大小最多差 1，每次调整常数次堆操作；偶数中位数规则要和题意对齐（较小 / 较大）。
- 需要 decrease-key 或「任意删」时，裸 `priority_queue` 不够，要么惰性删除，要么手写带句柄的堆。

原文：[二叉堆 - OI Wiki](https://oi-wiki.org/ds/binary-heap/)

## 6. 2026-10-19 · 单调栈 · 数据结构

**单调栈** · 数据结构

**一句话用途**：扫一遍序列，用栈维护「候选决策点」的单调性，顺便求出每个位置左边/右边第一个更大（或更小）的元素，以及「能看到多远」这类区间贡献。

**核心思想**  
栈里自顶向下严格单调（以递增栈为例：顶小底大）。新元素 \(x\) 入栈前，先把所有破坏单调性的栈顶弹掉，再压入 \(x\)。  
OI Wiki 例子：栈顶向下是 \(\{0,11,45,81\}\)，插入 \(14\) 时弹出 \(0,11\)，变成 \(\{14,45,81\}\)。被弹出的元素，它们「右边第一个更大」的位置往往就是当前 \(x\)——这正是模板题里要记的东西。

**怎么做（C++ 模板）**  
经典：「求每个位置右边第一个严格更大的下标」（洛谷 P5788）。从右往左扫，维护单调递减栈（顶小）：

```cpp
vector<int> nextGreater(const vector<int>& a) {
  int n = a.size();
  vector<int> ans(n, 0);  // 0 表示没有
  stack<int> st;          // 存下标，a[st] 单调递减
  for (int i = n - 1; i >= 0; --i) {
    while (!st.empty() && a[st.top()] <= a[i]) st.pop();
    if (!st.empty()) ans[i] = st.top() + 1;  // 1-based
    st.push(i);
  }
  return ans;
}
```

方向与比较符对照：
- 右第一个更大：右→左扫，弹 `<=`（或 `<`）
- 左第一个更大：左→右扫，同理
- 更小则把比较反过来

**POJ3250 Bad Hair Day**（OI Wiki 应用）：每头牛看右边，直到遇到第一头 \(\ge h_i\) 的牛；求 \(\sum c_i\)。从右往左维护高度单调栈，记录弹出位置（没弹出则到最右），差分/前缀和一下即可。

**离线 RMQ**（OI Wiki）：询问按右端点排序，扫到 \(r\) 时把元素插入单调栈；对当前询问，栈上第一个位置 \(\ge l\) 的元素即答案（栈上二分）。复杂度 \(O(q\log q + q\log n)\)，空间 \(O(n)\)。

**复杂度与坑**
- 每个下标最多入栈、出栈各一次 → 摊还 \(O(n)\)（离线 RMQ 另加排序/二分）。
- **严格 vs 非严格**：`>` 还是 `>=` 决定相等元素谁当「第一个」；题面写「大于」就弹 `<=`，写「大于等于」就弹 `<`。
- 栈里存**下标**不存值，否则算距离/贡献时还得回头找位置。
- 边界：栈空表示这一侧没有更大/更小，按题意填 \(0\)、\(n+1\) 或哨兵。

原文：[OI Wiki · 单调栈](https://oi-wiki.org/ds/monotonic-stack/)

## 7. 2026-10-20 · 单调队列 · 数据结构

**单调队列** · 数据结构

固定（或可滑动）窗口上的区间最值查询：每个元素进队出队各一次，整段变成 \(O(n)\)。

**核心思想**
求滑动窗口最大值时，若新来的 \(a[i]\) 比队尾还大，队尾那些更早、更小的数永远不可能再当最大值——先出队再进队。队列里存的是下标，值严格递减（求最小则递增），队头就是当前窗口最值。窗口右移时先把头上越界的下标弹掉。

小例子 \(a=[1,3,-1,-3,5,3,6,7]\)，\(k=3\)，维护递增队列求最小：
`1 → {1}` → `3 → {1,3}` → `-1` 清空 → `{-1}` → `-3` → `{-3}` → `5 → {-3,5}` → `3` 弹 5 → `{-3,3}` → 窗移，`-3` 出界 → `{3}`，再入 6、7 → `{3,6,7}`。

**怎么做（C++ 模板）**
```cpp
// Sliding window min / max; q stores indices; O(n)
void getmin(int n, int k, int a[]) {
  static int q[1000100];
  int head = 0, tail = -1;
  for (int i = 1; i < k; i++) {
    while (head <= tail && a[q[tail]] >= a[i]) tail--;
    q[++tail] = i;
  }
  for (int i = k; i <= n; i++) {
    while (head <= tail && a[q[tail]] >= a[i]) tail--;
    q[++tail] = i;
    while (q[head] <= i - k) head++;   // drop out-of-window head
    cout << a[q[head]] << ' ';
  }
}
// getmax: flip >= to <=（递减队列）
```
可变窗口（如花盆 P2698）：按 \(x\) 排序后双指针推进 \(R\)，用一增一减两个单调队列维护 \([L,R]\) 的 \(\max-\min\)；\(L\) 固定时该差关于 \(R\) 单调不减，所以对每个 \(L\) 取第一个满足 \(\ge D\) 的 \(R\) 即可，\(L,R\) 都只前进，仍 \(O(n)\)。

**复杂度与坑**
- 每个下标进/出各一次 → \(O(n)\)；空间 \(O(n)\)（或 \(O(k)\) 环形）。
- 队列里必须存**下标**，不能只存值，否则无法判断越界。
- 出队条件写反（`i-k` vs `i-k+1`）会差一个位置；下标从 0/1 起步要统一。
- 这不是 FIFO 队列：队尾也要删，用数组模拟双端队列或 `deque`。
- 与单调栈对比：栈管「最近更大/更小」；队列管「滑动区间最值」。两者常一起出现在「贡献法 / 子数组最值计数」里。

原文：[单调队列 - OI Wiki](https://oi-wiki.org/ds/monotonic-queue/)

## 8. 2026-10-21 · ST 表（Sparse Table）· 数据结构

**ST 表（Sparse Table）· 数据结构**

**一句话用途**：静态数组上做区间 max/min/gcd/按位与/按位或查询，预处理 \(O(n\log n)\)，单次查询 \(O(1)\)，不支持修改。

**核心思想**：只有运算同时满足结合律和「可重复贡献」（\(x \operatorname{opt} x = x\)，也就是幂等）时才能用。区间有重叠也不影响答案，所以任何 \([l,r]\) 都能用两段长度为 \(2^s\) 的预处理区间盖住，其中 \(s=\lfloor\log_2(r-l+1)\rfloor\)。举个例子，查 \([2,8]\) 时长度是 7、\(s=2\)，就取 \([2,5]\) 和 \([5,8]\)，下标 5 被算了两次，但 max 不在乎重复。区间和不幂等，重叠部分会被算两次，所以不能这样做（要么用前缀和，要么用 log 次拼接的倍增查询）。

**怎么做**：令 \(f(j,i)\) 表示 \([i, i+2^j-1]\) 上的结果，\(f(0,i)=a_i\)，转移是 \(f(j,i)=\max(f(j-1,i),\ f(j-1,i+2^{j-1}))\)。查询答案就是 \(\max(f(s,l),\ f(s,r-2^s+1))\)。

```cpp
// Sparse table for range max; written from the idea, not copied from OI Wiki
const int N = 100005, LOG = 17;   // 2^17 > 1e5
int st[LOG][N];                    // log dimension first: cache friendly
void build(int n, const int* a) {  // a is 1-indexed
    for (int i = 1; i <= n; ++i) st[0][i] = a[i];
    for (int j = 1; (1 << j) <= n; ++j)
        for (int i = 1; i + (1 << j) - 1 <= n; ++i)
            st[j][i] = max(st[j-1][i], st[j-1][i + (1 << (j-1))]);
}
int query(int l, int r) {
    int s = __lg(r - l + 1);       // or 31 - __builtin_clz(len)
    return max(st[s][l], st[s][r - (1 << s) + 1]);
}
```

如果用不了 `__lg`，就预处理一张对数表：`lg[1]=0; lg[i]=lg[i/2]+1;`

**复杂度与坑**：
1. 原文专门提到，数组应该开成 `st[LOG][N]`，不要开成 `st[N][LOG]`。这样内层循环按 i 连续访问内存，缓存局部性更好。
2. 不要在查询里调 `std::log`，又慢又可能有浮点误差，用 `__lg`、`__builtin_clz` 或预处理好的表。
3. 构建时内层循环的边界是 `i + 2^j - 1 <= n`，写错会越界读到没初始化的值。
4. 原文的模板题（Luogu P3865）有 2e6 次询问，必须开快读快写。
5. 区间 GCD 也能用 ST 表。原文用势能分析证明，预处理是 \(\Theta(n(\log n+\log w))\)，不是看上去的 \(n\log n\log w\)；单次查询是 \(\Theta(\log w)\)，线段树是 \(\Theta(\log n+\log w)\)。
6. 换个角度理解：按位与相当于每一位各自取 min，GCD 相当于每个质因数的指数各自取 min，本质上都是 RMQ。
7. 面试和实战里的变形：有修改就换线段树；需要不可重复贡献的运算（比如和、乘积），可以改成 \(O(\log n)\) 的倍增拼接查询，或者用 Disjoint Sparse Table（这是我补充的延伸，不是这篇原文的内容）。

**习题**：[「SCOI2007」降雨量](https://loj.ac/p/2279)、[Balanced Lineup](https://www.luogu.com.cn/problem/P2880)
**原文**：[OI Wiki · ST 表](https://oi-wiki.org/ds/sparse-table/)

## 9. 2026-10-22 · 树状数组（Fenwick Tree）· 数据结构

**每日 OI Wiki：树状数组（Fenwick Tree）· 数据结构**

**用途：** 树状数组维护能做差分的前缀信息，比如和、异或。单点修改和前缀查询都是 \( O(\log n) \)，常数小，代码短。配上差分、权值数组或者二维嵌套，可以处理区间加区间和、第 k 小、逆序对、子矩阵加和这类题。

**核心思想：** \( c[x] \) 管 \( a[x-\text{lowbit}(x)+1 \ldots x] \) 这一段。查询时沿 `x -= lowbit(x)` 往前跳；修改时沿 `x += lowbit(x)` 往上走，路过的正好是所有管着 x 的节点。基础部分你熟，下面只讲进阶用法。

**1. 区间加、区间和（两棵 BIT）。** 设差分 \( d_i=a_i-a_{i-1} \)，则
$$\sum_{i=1}^r a_i=(r+1)\sum_{i=1}^r d_i-\sum_{i=1}^r d_i\cdot i$$
一棵维护 \( d_i \)，一棵维护 \( d_i\cdot i \)。区间 \( [l,r] \) 加 v，就是在 l 处加 v、在 r+1 处加 −v。
```cpp
void add(int k, int v){ int v1 = k * v;          // fix k*v before the loop
  for (; k <= n; k += k & -k) t1[k] += v, t2[k] += v1; }
long long pre(int r){ long long s1 = 0, s2 = 0;
  for (int k = r; k; k -= k & -k) s1 += t1[k], s2 += t2[k];
  return (r + 1LL) * s1 - s2; }
// range_add(l,r,v): add(l,v), add(r+1,-v);  range_sum = pre(r) - pre(l-1)
```
坑：`v1` 要在循环前算好。写成 `t2[k] += k*v` 是错的，因为循环里的 k 已经不是原下标了。

**2. 二维 BIT。** 单点加、子矩阵查询，就是两层 lowbit 循环加容斥。内层要用独立的循环变量，不能直接改 y。子矩阵加、子矩阵和要维护四棵树，分别存 \( d \)、\( d\cdot i \)、\( d\cdot j \)、\( d\cdot i\cdot j \)。前缀查询的系数是 `(x+1)(y+1)t1 - (y+1)t2 - (x+1)t3 + t4`，修改时乘的是原坐标 x、y，不是循环变量。子矩阵加拆成四个单点加：\( (x_1,y_1) \) 和 \( (x_2+1,y_2+1) \) 加 +v，\( (x_1,y_2+1) \) 和 \( (x_2+1,y_1) \) 加 −v。

**3. 权值 BIT 求第 k 小，倍增做到 \( O(\log n) \)。** 二分加前缀查询是 \( O(\log^2 n) \)。从高位到低位倍增时，x 之前只加过更高的位，所以 \( \text{lowbit}(x+2^i)=2^i \)，\( c[x+2^i] \) 正好就是 \( [x+1,x+2^i] \) 的和，一次访问就够了。
```cpp
int kth(int k){ int x = 0, s = 0;
  for (int i = __lg(n); i >= 0; --i)
    if (x + (1 << i) <= n && s + t[x + (1 << i)] < k) x += 1 << i, s += t[x];
  return x + 1; }   // n+1 means not found
```
离散化时，修改操作会用到的值也要一起放进去。

**4. 逆序对。** 倒序扫 i，先查 \( b[1..a_i-1] \)，再给 \( b[a_i] \) 加 1。求严格逆序时这两步可以交换顺序。如果要的是 \( a_i\ge a_j \)，就改成查 \( b[1..a_i] \)，而且必须先查后加，不然会把 i=j 算进去。

**5. 维护最值（不能做差分）。** 区间查询从 r 往前跳。如果 `r - lowbit(r) >= l`，就合并整段 \( c[r] \)；否则只合并单点 \( a[r] \)，再 `r--`。条件别写成 `r-lowbit(r)+1>=l`，l=1 时会死循环。单点修改不能直接拿新值取 max，因为最值没有逆运算。要对每个祖先 i 重建：先令 `C[i]=a[i]`，再对 `j=1,2,4…<lowbit(i)` 合并 `C[i-j]`。查询和修改都是 \( O(\log^2 n) \)，比线段树慢。

**6. 两个实用技巧。** 第一，\( O(n) \) 建树可以写 `t[i]+=a[i]; if(i+lowbit(i)<=n) t[i+lowbit(i)]+=t[i];`，或者直接用前缀和算 `t[i]=sum[i]-sum[i-lowbit(i)]`。第二，多组数据时用时间戳，`tag[k]!=Tag` 的位置当作 0，不用每组都 memset。

**复杂度与适用范围：** 求和类单次操作 \( O(\log n) \)，二维 \( O(\log n\log m) \)，最值类 \( O(\log^2 n) \)。信息能差分、运算可逆就用 BIT；运算不可逆或者需要区间赋值，就用线段树，明天讲。

原文：[OI Wiki · 树状数组](https://oi-wiki.org/ds/fenwick/)

## 10. 2026-10-23 · 线段树基础 · 数据结构

**线段树基础** · 数据结构

一句话用途：在序列上维护可合并的区间信息，单点/区间修改与查询都做到 \(O(\log N)\)；比树状数组更通用（任意幺半群信息、区间改、复杂合并）。

核心思想：每个结点管一段 \([l,r]\)，左右儿子管 \([l,m]\)、\([m+1,r]\)。查询时把目标区间拆成 \(O(\log N)\) 个「极大线段树结点」再合并；区间改时只改这些极大结点并打懒惰标记（lazy），子孙的实际更新推迟到真正访问时再 `push_down`。

信息必须是幺半群：合并 \(\circ\) 可结合、有单位元；合并**不必交换**，必须严格从左到右。典型例子：区间和、最大/最小、异或、矩阵乘、仿射复合。最大子段和要额外带 `sum/lma/rma/ma` 四元组才能合并。

怎么做（竞赛常用：堆式存储 + 区间加求和）：

```cpp
// Info: range length + sum; Transform: range add
struct Info {
  long long len = 0, sum = 0;
  Info operator+(const Info& o) const { return {len + o.len, sum + o.sum}; }
};
struct Transform {
  long long v = 0;
  explicit operator bool() const { return v != 0; }
  Transform operator+(const Transform& o) const { return {v + o.v}; }
  Info operator()(const Info& x) const { return {x.len, x.sum + v * x.len}; }
};

#define lc(x) ((x)<<1)
#define rc(x) ((x)<<1|1)
vector<Info> val; vector<Transform> lazy;
void push_up(int cr) { val[cr] = val[lc(cr)] + val[rc(cr)]; }
void lazy_update(int cr, const Transform& f) {
  val[cr] = f(val[cr]); lazy[cr] += f;
}
void push_down(int cr) {
  if (!lazy[cr]) return;
  lazy_update(lc(cr), lazy[cr]); lazy_update(rc(cr), lazy[cr]);
  lazy[cr] = {};
}
// modify [tl,tr] by f; push_down before children, push_up on the way back
void modify(int cr, int ll, int rr, int tl, int tr, const Transform& f) {
  if (tl <= ll && rr <= tr) return lazy_update(cr, f);
  push_down(cr);
  int mm = ll + ((rr - ll) >> 1);
  if (tl <= mm) modify(lc(cr), ll, mm, tl, tr, f);
  if (mm < tr) modify(rc(cr), mm + 1, rr, tl, tr, f);
  push_up(cr);
}
Info query(int cr, int ll, int rr, int tl, int tr) {
  if (tl <= ll && rr <= tr) return val[cr];
  push_down(cr);
  int mm = ll + ((rr - ll) >> 1);
  Info res;  // identity
  if (tl <= mm) res = query(lc(cr), ll, mm, tl, tr);
  if (mm < tr) res += query(rc(cr), mm + 1, rr, tl, tr);
  return res;
}
```

区间加+乘（洛谷 P3373）用仿射 \(x\mapsto ax+b\) 一个标记即可：复合 `(a2,b2)∘(a1,b1)=(a2·a1, a2·b1+b2)`，作用到和上 `sum' = a·sum + b·len`。两个 lazy（mul/add）时下传必须先乘后加。

复杂度与坑：
- 建树/空间 \(\Theta(N)\)（堆式常开 `4N`）；单次改查 \(O(\log N)\)。
- 中点写 `ll + (rr-ll)/2`，别写 `(ll+rr)/2`（溢出/负数）。
- 访问儿子前必下传；刚打过 lazy 的结点回溯时不要用未更新的儿子 `push_up` 覆盖。
- 区间加维护和时必须带长度（或用端点算），否则增量不对。
- 合并无交换时（最大子段和等）左右累计要分开再拼，非递归查询同理。
- \(N\sim10^9\)：离线离散化，或动态开点（\(O(q\log N)\) 结点）；强制在线才必须动态开。
- 标记永久化要求标记复合可交换（纯加/纯乘可以；仿射/赋值一般不行），树套树/可持久化里很常用。
- 进阶：zkw 非递归常数更小；线段树二分把「最远满足谓词的端点」做到 \(O(\log N)\)；权值线段树当平衡树用。

## 11. 2026-10-24 · 双指针（算法 / 技巧）

**每日 OI Wiki · 双指针（算法 / 技巧）**

一句话用途：利用单调性让两个下标都只往一个方向走，把 \(O(n^2)\) 的枚举压到 \(O(n)\)；再配上差分、单调队列、二分或莫队，能解更复杂的题。

**1. 同向滑窗：维护区间信息**
能用的前提有两个：往区间里加一个元素、删一个元素都是 \(O(1)\)；条件对 \(l\) 单调，也就是 \([l,r]\) 满足时 \([l+1,r]\) 也满足。原文例题是 LC 713「乘积小于 K 的子数组」。正整数越乘越大，所以每个 \(r\) 都有一个最左的合法 \(l\)，以 \(r\) 结尾的合法区间正好有 \(r-l+1\) 个：
```cpp
long long p = 1, ans = 0; int l = 0;
for (int r = 0; r < n; ++r) {
  p *= a[r];
  while (l <= r && p >= k) p /= a[l++];
  ans += r - l + 1;   // standard counting sliding window
}
```
有三个坑。第一，单调性靠的是元素都是正数，出现 0 或负数这个写法就不成立了，要换成前缀和加有序结构。第二，\(k\le 1\) 时 `l` 会推到 `r+1`，所以 `l<=r` 这个判断不能省。第三，如果要维护的是区间最大值减最小值（比如习题 LC 1438），删除就不是 \(O(1)\) 了，要用两个单调队列分别维护最大值和最小值。

**2. 树上双指针（原文例题 P3066）**
题目是：对每个点 \(u\)，统计它子树里到 \(u\) 距离不超过 \(t\) 的点有多少个。dfs 时用一个栈存从根到当前点的链，同时记下每个点到根的距离 \(dis\)。对 \(u\)，在栈上二分找出最浅的祖先 \(p\)，满足 \(dis_u-dis_p\le t\)。然后做树上差分：`cnt[u]++`、`cnt[fa[p]]--`，最后按子树求和。原文特别提醒，这里的 \(p\) 不能像在序列上那样一步步暴力移动。dfs 回溯后链就变了，指针会往回退，均摊分析不成立，最坏会退化到 \(O(n^2)\)。所以要用二分，总复杂度 \(O(n\log n)\)。

**3. 子序列匹配**
判断 \(t\) 是不是 \(s\) 的子序列：用 \(i\) 扫 \(s\)，每当 \(s_i=t_j\) 就让 \(j\) 前进一位，最后 \(j=|t|\) 就是子序列，复杂度 \(O(|s|)\)。贪心地尽早匹配是对的，因为早匹配不会让后面的选择变少。原文例题是 LC 524。如果要拿很多个 \(t\) 和同一个 \(s\) 比对，可以先预处理 `nxt[i][c]`，表示位置 \(i\) 之后字符 \(c\) 第一次出现的位置，这样每次查询只要 \(O(|t|)\)。这一点原文没展开，是我补充的常见变形。

**4. 相向逼近：利用有序性**
例题是有序数组上的两数之和（LC 167）。如果 \(a_l+a_r>\text{target}\)，那么 \(a_r\) 和 \(l\) 之后任何一个数相加都只会更大，所以 \(r\) 可以整个排除，让 \(r\) 减一；和偏小时同理，让 \(l\) 加一。每一步都排除一整行或一整列，所以总共 \(O(n)\)。三数之和（习题 LC 15）是先排序、固定一个数，再做相向双指针，复杂度 \(O(n^2)\)，要注意跳过重复值。归并排序里合并两个有序段也是同样的思路。

**5. 快慢指针找环（Floyd 判圈）**
慢指针每次走 1 步，快指针每次走 2 步，两者相遇就说明有环。找入口的方法是：设环外的链长为 \(a\)、环长为 \(C\)，相遇时慢指针走了 \(k\) 步，快指针比它多走的 \(k\) 步一定是 \(C\) 的整数倍。这时把一个指针放回起点，两个指针都每次走 1 步，各走 \(a\) 步后就在入口相遇，因为 \(k+a\equiv a \pmod C\)。
```cpp
int f = 0, s = 0;
do { if (nxt[f]==-1 || nxt[nxt[f]]==-1) return NO_CYCLE;
     f = nxt[nxt[f]]; s = nxt[s]; } while (f != s);
s = 0; while (s != f) s = nxt[s], f = nxt[f];   // s is the cycle entry
```
面试里常见的延伸有两个：从入口出发绕一圈数步数就是环长；LC 287 找重复数，可以把 `i -> nums[i]` 看成一张函数图，再用 Floyd 找环的入口。

**复杂度与坑**
同向双指针是 \(O(n)\)，前提是指针从不回退，所以写之前先想清楚单调性从哪来。计数题用 `r-l+1` 累加答案；求最长或最短区间时，要分清答案该在 `while` 收缩之前还是之后更新。相向双指针要求数组先排好序。莫队可以看成离线排序加双指针的推广。

原文：[OI Wiki · 双指针](https://oi-wiki.org/misc/two-pointer/)

## 12. 2026-10-25 · 主席树（可持久化权值线段树）· 数据结构

**每日讲解｜主席树（可持久化权值线段树）· 数据结构**

**它能做什么：** 不带修改的「区间第 k 小」，以及更一般的「区间 [l, r] 内值域上的统计」，比如有多少个数 ≤ x。单次查询 \( O(\log n) \)。

**核心思想：** 主席树是两个想法叠在一起。第一，在值域上建一棵权值线段树，节点存「落在这段值域里的数有几个」。第二，按下标从 1 到 n 依次插入，每插一次就是一个新版本 `rt[i]`。插入只会改根到叶子那一条链上的 \( O(\log n) \) 个节点，所以新版本只把这条链复制一份，其余子树直接沿用旧版本的指针。这种「路径复制」就是持久化的全部内容。

计数满足可减性，所以 `rt[r]` 减去 `rt[l-1]` 就等于区间 [l, r] 的权值线段树，跟前缀和的道理完全一样。查询时两棵树同步往下走：先算左儿子的计数差 `x`，如果 `k ≤ x` 就进左子树，否则 `k -= x` 进右子树。

举个小例子：a = [3, 1, 2]，查 [2, 3] 里第 1 小。`rt[3]` 减 `rt[1]` 得到的是只含 {1, 2} 的树，从根往左走，答案是 1。

**怎么做（核心模板）：**
```cpp
int update(int k, int l, int r, int root) {     // insert value k on old root; return new root
  int dir = ++tot;
  ls[dir] = ls[root], rs[dir] = rs[root], sum[dir] = sum[root] + 1;
  if (l == r) return dir;
  int mid = l + r >> 1;
  if (k <= mid) ls[dir] = update(k, l, mid, ls[dir]);
  else          rs[dir] = update(k, mid + 1, r, rs[dir]);
  return dir;
}
int query(int u, int v, int l, int r, int k) {   // u = rt[l-1], v = rt[r]
  if (l == r) return l;
  int mid = l + r >> 1, x = sum[ls[v]] - sum[ls[u]];
  return k <= x ? query(ls[u], ls[v], l, mid, k)
                : query(rs[u], rs[v], mid + 1, r, k - x);
}
// preprocess: discretize, then insert one by one
sort(ind+1, ind+n+1); len = unique(ind+1, ind+n+1) - ind - 1;
rt[0] = build(1, len);
for (int i = 1; i <= n; ++i)
  rt[i] = update(lower_bound(ind+1, ind+len+1, a[i]) - ind, 1, len, rt[i-1]);
// answer: ind[query(rt[l-1], rt[r], 1, len, k)]
```

**复杂度和容易错的地方：**
- 建树 \( O(n) \)，每次插入和查询 \( O(\log n) \)。空间是 \( 2n - 1 + n(\lceil \log_2 n \rceil + 1) \)，按原文建议直接开 `n << 5`。
- 必须动态开点、显式存 `ls`/`rs`，不能用堆式 `2x`/`2x+1`，因为不同版本会共享子树。
- 值域要先离散化，最后用 `ind[...]` 映射回原值，这一步很容易忘。（离散化本身偏基础，已跳过单独讲，写法并在这里。）
- `build` 可以省掉：让 `rt[0] = 0`，把 0 号节点当空树（`sum[0]=0`，左右儿子都指向 0），还能省 \( 2n \) 个节点。这一条是补充，原文没写。
- 每次插入都必须新开节点，不能就地改旧节点，否则历史版本会被改坏。
- 带修改的区间第 k 小不能直接这么做，要换成树状数组套主席树，或者整体二分。
- 原文拓展还讲了可持久化并查集：把 `fa` 放进可持久化数组，按秩合并，不做路径压缩。

**原文：** [OI Wiki · 可持久化线段树](https://oi-wiki.org/ds/persistent-seg/)

## 13. 2026-10-26 · 线段树合并与分裂（数据结构 / 技巧）

**每日讲解 · 线段树合并与分裂（数据结构 / 技巧）**

**一句话用途：** 用动态开点的权值线段树维护可重集，把两个集合合成一个（合并），或者按值域切出一段做成新集合（分裂）。最典型的场景是树上每个点有一个集合，需要自下而上地汇总到父节点。

**核心思想**

合并的思路很直接：两棵树从根开始同步递归。如果某一侧的对应节点为空，就直接返回另一侧的节点，整棵子树原样接过来，一次都不用往下走。只有两边都非空时才继续递归，到叶子处再合并两边的值。所以花费只和两棵树「重叠的节点数」有关。OI Wiki 原文的结论是：单次合并两棵满树是 \(O(n)\)；但在常见的权值线段树场景里，所有树的总点数大致是 \(n\log n\) 级别，而且每棵树一般只被合并一次，所以全部合并下来总共是 \(O(n\log n)\)。原文也提到，有些情况下可并堆会更合适。

分裂是合并的逆过程，只对有序的值域有意义。从 \([1,N]\) 的树里切出 \([l,r]\) 时：如果当前区间和 \([l,r]\) 不相交，或者当前节点不存在，就直接返回；如果当前区间完全落在 \([l,r]\) 里，就把整棵子树挂到新树上，并把旧树这一侧的指针清空；部分相交时，给新树开一个节点再往下递归。被断开的边最多 \(\log n\) 条，所以单次分裂是 \(O(\log n)\)，和一次区间查询一样。

**小例子：** 在雨天的尾巴（P4556）里，「路径 \(u\to v\) 上每个点发一袋第 \(z\) 种粮食」可以用树上差分改成四次单点修改：在 \(u\) 和 \(v\) 处各 +1，在 \(\mathrm{lca}\) 和 \(\mathrm{fa}(\mathrm{lca})\) 处各 −1，位置都是值域上的 \(z\)。然后做一遍 DFS，把每个子节点的权值树合并进父节点，再查父节点上数量最多的种类。

**模板（来自原文）**

```cpp
// merge: reuse a's nodes, fold b into a
int merge(int a, int b, int l, int r) {
  if (!a) return b;
  if (!b) return a;
  if (l == r) { /* leaf: e.g. cnt[a] += cnt[b] */ return a; }
  int mid = (l + r) >> 1;
  tr[a].l = merge(tr[a].l, tr[b].l, l, mid);
  tr[a].r = merge(tr[a].r, tr[b].r, mid + 1, r);
  pushup(a);
  return a;
}

// split: move value range [l,r] from p into q (q starts at 0)
void split(int &p, int &q, int s, int t, int l, int r) {
  if (t < l || r < s) return;
  if (!p) return;
  if (l <= s && t <= r) { q = p; p = 0; return; }
  if (!q) q = New();
  int m = s + t >> 1;
  if (l <= m) split(ls[p], ls[q], s, m, l, r);
  if (m < r)  split(rs[p], rs[q], m + 1, t, l, r);
  push_up(p); push_up(q);
}
```

P5494（线段树分裂模板）里的五种操作，都可以由上面两个函数加上单点修改、区间求和、第 \(k\) 小拼出来。

**复杂度与易错点**

1. 原文的 merge 会直接改写并复用 a 的节点，合并之后 b 那棵树就不能再单独用了。如果离线要回头查询某个子节点合并前的答案，就得在合并它之前先查好。如果合并后还要查旧版本，就要改成每次新开节点，代价是更多空间。这条是根据代码推出来的，原文没有写。
2. 原文特别提醒：如果合并和分裂都会出现，合并时要回收被吞掉的 b 节点，否则分裂时可能出现同一个节点被重复占用的问题。
3. 节点池要开到「初始插入次数 × \(\log V\)」这个量级，再给分裂时新开的节点留出余量。
4. 树上合并时，DFS 一定要先把所有子节点合并进来，再查询当前点的答案。叶子处的合并逻辑（比如求和，或者取最大值和对应编号）要和 pushup 保持一致。
5. 用了树上差分之后，叶子上的计数可能是负数或 0，求「出现最多的种类」时要处理 0 的情况。比如 P4556 要求没有粮食时输出 0。

**习题：** P4556、P5494、P1600 天天爱跑步、P4577 领导集团问题、P2824 排序（用分裂/合并维护有序段）。

原文：[OI Wiki · 线段树合并与分裂](https://oi-wiki.org/ds/seg-merge-split/)

## 14. 2026-10-27 · 李超线段树（Li Chao Tree）｜数据结构

**每日讲解 · 李超线段树（Li Chao Tree）｜数据结构**

**用途：** 在线维护一堆一次函数或线段，支持「插入一条直线或线段」和「问 \(x=k\) 处的最大值（或最小值）」两种操作。插入整条直线 \(O(\log n)\)，插入定义域 \([l,r]\) 的线段 \(O(\log^2 n)\)，查询 \(O(\log n)\)。

**核心思想：** 每个节点只存一条「懒标记线段」，而且这个标记永远不往下推（标记永久化）。查询时把根到叶子路径上 \(O(\log n)\) 个标记都算一遍，取最大的那个。插入的关键是比较两条一次函数 \(f\) 和 \(g\) 在区间中点 \(m\) 处的值，在中点更优的那条留在当前节点。两条直线最多相交一次，所以另一条线只可能在左半边或者右半边胜出，于是只需要递归一侧。具体做法是：先保证 \(g\) 在中点处更优（不是就交换）；如果左端点处 \(f\) 更优，交点在左半边，把 \(f\) 递归到左儿子；如果右端点处 \(f\) 更优，就递归到右儿子；如果两个端点都是 \(g\) 更优，\(f\) 直接丢掉。两侧最多只有一个条件成立，这正是复杂度能做到 \(O(\log n)\) 的原因。

小例子：在 \([1,8]\) 上已经有 \(g=x\)，现在插入 \(f=9-x\)。中点 \(m=4\) 处 \(f=5>g=4\)，所以交换，当前节点留下 \(9-x\)。然后看端点：左端点 \(x=1\) 处新的 \(f=x\) 等于 1，不如 8；右端点 \(x=8\) 处 \(f=8\) 大于 1，所以把 \(x\) 递归进右儿子 \([5,8]\)。

**模板（C++，按 P4097 求最大值，平局取编号小的）：**
```cpp
int cmp(double a,double b){ if(a-b>eps) return 1; if(b-a>eps) return -1; return 0; }
// node root is fully covered by the insert range
void upd(int root,int cl,int cr,int u){
  int &v=s[root], mid=(cl+cr)>>1;
  int bm=cmp(calc(u,mid),calc(v,mid));
  if(bm==1||(!bm&&u<v)) swap(u,v);          // keep v as the better one at mid
  int bl=cmp(calc(u,cl),calc(v,cl)), br=cmp(calc(u,cr),calc(v,cr));
  if(bl==1||(!bl&&u<v)) upd(root<<1,cl,mid,u);
  if(br==1||(!br&&u<v)) upd(root<<1|1,mid+1,cr,u);   // at most one of these fires
}
// insert a segment: split into O(log) full nodes, then upd each
void update(int root,int cl,int cr,int l,int r,int u){
  if(l<=cl&&cr<=r){ upd(root,cl,cr,u); return; }
  int mid=(cl+cr)>>1;
  if(l<=mid) update(root<<1,cl,mid,l,r,u);
  if(mid<r)  update(root<<1|1,mid+1,cr,l,r,u);
}
// query: max over all tags on the root-to-leaf path
pdi query(int root,int l,int r,int d){
  if(r<d||d<l) return {0,0};
  int mid=(l+r)>>1; double res=calc(s[root],d);
  if(l==r) return {res,s[root]};
  return pmax({res,s[root]}, pmax(query(root<<1,l,mid,d), query(root<<1|1,mid+1,r,d)));
}
```
插入的如果是整条直线，就直接在根上调用 `upd`，省掉拆区间那一步，复杂度降到 \(O(\log n)\)。

**合并：** 合并两棵动态开点的李超树时，把 \(v\) 节点上的线段插进 \(u\) 的子树，再递归合并左右儿子。原文用势能分析：每条线段每移动一次，要么深度加一，要么被删掉，所以总复杂度是 \(O(n\log n)\)。它常和 DSU on tree 或树形 DP 搭配，比如原文习题 CF932F。

**复杂度与坑：**
- 竖直线段会导致斜率除以零。原文的处理是把它当成定义域为 \([x,x]\) 的常数函数 \(y=\max(y_0,y_1)\)。
- 节点上的标记不等于「该区间中点处的最优线段」，因为标记从不下推，所以查询必须把整条路径上的标记都比一遍，不能只看叶子。
- 模板用的是浮点数加 eps。在坐标和斜率都是整数的题里，更推荐直接用 `long long` 存 \(k\) 和 \(b\)，避免精度问题（补充建议，不是原文）。求最小值时，把比较方向反过来就行。
- 平局时要按题意判编号（P4097 要求编号最小），中点、左端点、右端点三处比较都要带上这个判断。
- 跟凸包优化或斜率优化比（补充）：李超树不要求斜率或查询点有单调性，也支持在线插入线段，代价是多一个 log。斜率优化 DP 里，如果斜率不单调，李超树往往是最省心的写法。

## 15. 2026-10-28 · 树链剖分（重链剖分 + 长链剖分）｜数据结构

**每日讲解 · 树链剖分（重链剖分 + 长链剖分）｜数据结构**

**一句话用途**：把树拆成若干条 DFS 序连续的链，这样「路径修改/查询」「子树修改/查询」都能变成在线段树上操作 \(O(\log n)\) 段区间。顺带还能以很小的常数求 LCA。

**核心思想**：每个点选子树最大的儿子做重儿子，首尾相连的重边组成重链。关键性质有两条。第一，往下走一条轻边，子树大小至少减半，所以任意路径最多被切成 \(O(\log n)\) 条重链。第二，DFS 时先走重儿子，于是每条重链在 dfn 上连续，每棵子树也连续，子树 \(x\) 对应的就是 \([dfn_x, dfn_x+siz_x-1]\)。

**模板（C++）**

```cpp
void dfs1(int u,int f){ fa[u]=f; dep[u]=dep[f]+1; siz[u]=1;
  for(int v:G[u]) if(v!=f){ dfs1(v,u); siz[u]+=siz[v];
    if(siz[v]>siz[son[u]]) son[u]=v; } }
void dfs2(int u,int t){ top[u]=t; dfn[u]=++idx; rnk[idx]=u;
  if(son[u]) dfs2(son[u],t);
  for(int v:G[u]) if(v!=son[u]&&v!=fa[u]) dfs2(v,v); }
// path ops: jump the deeper chain-top each time
long long pathQuery(int u,int v){ long long r=0;
  while(top[u]!=top[v]){ if(dep[top[u]]<dep[top[v]]) swap(u,v);
    r+=seg.query(dfn[top[u]],dfn[u]); u=fa[top[u]]; }
  if(dep[u]>dep[v]) swap(u,v);
  return r+seg.query(dfn[u],dfn[v]); }
// LCA: same jump; the shallower endpoint is the LCA
```

路径修改的写法和上面一样，只是把 query 换成 update。子树操作直接对 \([dfn_x, dfn_x+siz_x-1]\) 做区间操作。

**换根（LOJ 139）**：路径操作不受换根影响，照常做。子树操作要按 \(u\) 和当前根 root 的位置分三种情况。如果 \(u=\) root，就是整棵树。如果 \(u\) 在原树上是 root 的祖先，先找到 \(u\) 往 root 方向的那个儿子 \(v\)：从 root 沿重链往上跳，直到 \(dep(top(v))\le dep(u)+1\)，然后取 \(v=rnk(dfn(top(v))+dep(u)+1-dep(top(v)))\)。这时要操作的是 \(v\) 子树的补集，也就是 \([1,dfn_v)\cup[dfn_v+siz_v,n]\)。其他情况照常做。

**长链剖分**：重儿子改成子树深度最大的儿子。从任一点到根，轻边切换次数是 \(O(\sqrt n)\) 级别，所以长链剖分不用来做路径查询，主要有两个用处。
- 优化深度维 DP，比如 CF1009F：父节点直接继承重儿子的 DP 数组（在前面插一个元素，做法是一条链共用一块内存，用指针偏移），轻儿子的数组暴力合并进来。因为所有链长加起来是 \(n\)，总复杂度是 \(O(n)\)。
- k 级祖先查询：预处理 \(O(n\log n)\)，查询 \(O(1)\)。先用倍增跳 \(2^i\le k\) 那一步，再在链顶预存的向上、向下长度为 \(d\) 的表里直接查。

**复杂度与坑**
- 重剖加线段树：预处理 \(O(n)\)，每次路径操作 \(O(\log^2 n)\)，实际常数很小，一般卡不满。
- 跳链时比的是 `dep[top[u]]`，不是 `dep[u]`，这是最常见的写错点。
- 最后同链那一段，要先 swap 成 `dfn[u]<=dfn[v]` 再操作。
- 线段树的下标是 dfn，建树时初值要用 `a[rnk[i]]`。
- 边权题的通常做法是把边权下放到深度更大的端点，最后同链那段写成 `dfn[u]+1`，把 LCA 排除掉（常见做法，原文没有展开讲）。
- `son[0]` 要保证 `siz[0]=0`，递归太深的话考虑手写栈。

## 16. 2026-10-29 · 树上启发式合并（DSU on tree）｜数据结构

**每日讲解 · 树上启发式合并（DSU on tree）｜数据结构**

**一句话用途**：离线求「每个子树的某种可加统计」（颜色种类、众数之和等），用轻重儿子继承，把暴力 \(O(n^2)\) 压到 \(O(n\log n)\)，不用树套树。

**核心思想**：和重链剖分一样，重儿子 = 子树最大的儿子。对每个 \(u\)：先递归轻儿子并**清空**其对全局桶的影响；再递归重儿子并**保留**；最后把各轻儿子子树按 dfn 区间暴力加回来，加上 \(u\) 自己，记答案。不 keep 时再整段清掉。

为何是 \(O(n\log n)\)：任意点到根最多 \(O(\log n)\) 条轻边（走轻边子树至少减半）。一个点被暴力遍历的次数 ≈ 到根轻边数 \(+1\)，故总复杂度 \(O(n\log n)\)。重儿子那条链靠「继承」几乎白嫖。

**模板骨架（递归）**

```cpp
void dfs0(int u,int p){ // siz / big / L / R / Node
  L[u]=++totdfn; Node[totdfn]=u; sz[u]=1;
  for(int v:g[u]) if(v!=p){
    dfs0(v,u); sz[u]+=sz[v];
    if(!big[u]||sz[v]>sz[big[u]]) big[u]=v;
  }
  R[u]=totdfn;
}
void dfs1(int u,int p,bool keep){
  for(int v:g[u]) if(v!=p&&v!=big[u]) dfs1(v,u,false); // 轻：算完清空
  if(big[u]) dfs1(big[u],u,true);                         // 重：保留
  for(int v:g[u]) if(v!=p&&v!=big[u])
    for(int i=L[v];i<=R[v];i++) add(Node[i]);             // 轻儿子暴力加回
  add(u); ans[u]=getAns();
  if(!keep) for(int i=L[u];i<=R[u];i++) del(Node[i]);
}
```

`add`/`del`/`getAns` 按题意改：颜色种类就维护 `cnt[c]` 与 `totColor`；众数题维护「当前最大出现次数 + 对应颜色和」。

**迭代写法**：用重剖 dfn 倒序扫。重链连续，非链顶可直接继承上一节点；链顶扫完清空。省递归栈，链状树更稳。

**适用边界**
- 要离线、无修改；信息可从「集合贡献」里加减。
- 比树上莫队常数和写法通常更友好；能水一部分树套树部分分。
- 经典例：CF600E（子树众数颜色之和）、子树不同颜色数；CF741D 一类用异或桶 + DSU 优化的路径题。

**坑**
- 先轻后重，顺序反了就继承错。
- `keep=false` 必须整段 `del`，漏清会污染兄弟。
- dfn 建完才能按区间暴力加轻儿子；别边建边用错序。
- 颜色值域大要离散化（或哈希）；`cnt` 下标用离散后的 id。

**练手**：[CF600E Lomsat gelral](https://codeforces.com/problemset/problem/600/E)、[树上颜色种类模板题（自建）](https://oi-wiki.org/graph/dsu-on-tree/)

## 17. 2026-10-30 · 分块思想与块状数组（数据结构 / 思想）

**每日讲解 · 分块思想与块状数组（数据结构 / 思想）**

**一句话用途：** 线段树、树状数组维护不了的信息（比如「区间内 ≥ c 的个数」并且带区间加），可以用 \(O(\sqrt n)\) 的块加上块内预处理暴力拿下，通用性比线段树强，代价是复杂度多一个根号。

**核心思想**
把长为 \(n\) 的数组按块长 \(s\) 切开，每块预存一份汇总信息（和、排好序的副本、整块标记等）。任何区间 \([l,r]\) 都能拆成三段：左边残块、中间若干整块、右边残块。残块逐个暴力处理，花 \(O(s)\)；整块直接用汇总信息，花 \(O(n/s)\) 乘上单块代价。单次操作是 \(O(n/s+s)\)，由均值不等式取 \(s=\sqrt n\) 得到 \(O(\sqrt n)\)。

举个例子，区间加加区间和（LOJ 6280）：每块存块和 \(b_i\) 和整块加标记。整块修改只动标记，残块逐个改 \(a_i\)，同时别忘了更新 \(b_i\)。

**两种平衡的变形（原文给的）**
- 区间和 2（修改 \(O(\sqrt n)\)、查询 \(O(1)\)）：维护「块内前缀和」和「以整块为单位的前缀和」。修改要重算一个块内的前缀和加上块级前缀和，是 \(O(T+n/T)\)；查询三段都直接查前缀和，是 \(O(1)\)。适合查询远多于修改的场景。
- 对询问分块：把修改先攒下来，查询时把攒着的最多 \(T\) 个修改的影响逐个补上，花 \(O(T)\)；每攒满 \(T\) 个就 \(O(n)\) 重建一次前缀和。总复杂度是 \(O(mT+nm/T)\)，原文取 \(T=\sqrt n\) 得到 \(O(m\sqrt n)\)。这是「对时间分块」，和对序列分块是对偶的。

**模板：建块（OI Wiki 块状数组页的写法）**
```cpp
num = sqrt(n);
for (int i = 1; i <= num; i++)
  st[i] = n / num * (i - 1) + 1, ed[i] = n / num * i;
ed[num] = n;                       // 最后一块兜住余数
for (int i = 1; i <= num; i++) {
  for (int j = st[i]; j <= ed[i]; j++) belong[j] = i;
  size[i] = ed[i] - st[i] + 1;
}
```

**经典题：教主的魔法（洛谷 P2801），区间加加区间内 ≥ c 的计数**
关键在于每块维护一份排好序的副本 `t`，再加一个整块加标记 `delta`（标记永久化，不下放）。
```cpp
void Sort(int k){ for(int i=st[k];i<=ed[k];i++) t[i]=a[i]; sort(t+st[k],t+ed[k]+1); }
void Modify(int l,int r,int c){
  int x=belong[l], y=belong[r];
  if(x==y){ for(int i=l;i<=r;i++) a[i]+=c; Sort(x); return; }
  for(int i=l;i<=ed[x];i++) a[i]+=c;
  for(int i=st[y];i<=r;i++) a[i]+=c;
  for(int i=x+1;i<y;i++) delta[i]+=c;   // 整块只打标记，块内相对顺序不变
  Sort(x); Sort(y);                      // 残块改了值就要重排
}
int Answer(int l,int r,int c){
  int ans=0, x=belong[l], y=belong[r];
  if(x==y){ for(int i=l;i<=r;i++) if(a[i]+delta[x]>=c) ans++; return ans; }
  for(int i=l;i<=ed[x];i++) if(a[i]+delta[x]>=c) ans++;
  for(int i=st[y];i<=r;i++) if(a[i]+delta[y]>=c) ans++;
  for(int i=x+1;i<y;i++)
    ans += ed[i]-(lower_bound(t+st[i],t+ed[i]+1,c-delta[i])-t)+1;
  return ans;
}
```
原文给的复杂度是 \(O(q\sqrt n\log n)\)。整块加不破坏块内的有序性，这是能只打标记的根本原因。

**变形：区间赋值加区间内 ≤ c 的计数（寒夜方舟）**
赋值会抹掉块内结构，所以标记要下放：`delta` 用一个哨兵值（原文用 `0x3f3f3f3f3f3f3f3f`）表示「未整体赋值」。动残块之前先 `PushDown`，把标记写回 `a` 和 `t` 并清掉，改完再 `Sort`。查询整块时，没有标记就二分 `t`，有标记就直接判断 `delta[i] <= c`，成立则整块计入 `size[i]`。

**复杂度与坑**
- 块长不一定取 \(\sqrt n\)。教主的魔法这种每块要排序或二分的，修改约是 \(O(s\log s+n/s)\)，查询约是 \(O(s+(n/s)\log s)\)，把块长调大到大约 \(\sqrt{n\log n}\) 更平衡。这条是按原文复杂度推的，不是原文结论；原文推荐看 2017 年集训队论文、徐明宽的《非常规大小分块算法初探》。
- 边界上最容易错的是 `x==y` 的同块情况，必须单独处理，否则会把残块重复算两遍。
- 整块加和整块赋值的标记语义不同：加法可以永久化，赋值必须先 PushDown 再碰残块。改了残块的值，要更新块汇总（`b_i` 或重排 `t`）。
- 查询整块时，阈值要减去标记再二分（`c - delta[i]`），不要把标记加到 `t` 上。
- 分块的用武之地在于信息不可合并或难合并的问题，比如区间众数（P4168 蒲公英）、区间第 k 小带修改等。离线情况下，莫队就是基于分块思想的，也就是下一课。

## 18. 2026-10-31 · 普通莫队（Mo's algorithm）｜算法 · 离线区间询问

**每日讲解 · 普通莫队（Mo's algorithm）｜算法 · 离线区间询问**

**一句话用途：** 一类离线区间询问，只要能从 \([l,r]\) 的答案以 \(O(1)\) 走到相邻区间（左右端点各挪一格），就能在 \(n,m\) 同阶时用 \(O(n\sqrt n)\) 回答全部询问。它适合那种不能合并、线段树维护不了的统计，比如区间内相同颜色的配对数、区间众数相关的计数。

**核心思想：** 先把询问离线排序，然后用两个指针一格一格地暴力挪动，每挪一格做一次 add 或 del。排序规则是第一关键字取 \(l\) 所在块的编号，第二关键字取 \(r\)。均摊下来，同一块内 \(r\) 单调移动，每块最多走 \(O(n)\)，共 \(\sqrt n\) 块；\(l\) 在块内每次最多挪一个块长，所以两边合计都是 \(O(n\sqrt n)\)。

**块长要按 \(m\) 取：** 设块长为 \(S\)，总移动量是 \(O(n^2/S + mS)\)，取 \(S = n/\sqrt m\) 时最优，总复杂度为 \(O(n\sqrt m)\)。原文特别提醒，如果 \(m\) 和 \(\sqrt n\) 同阶，却把块长误设成 \(\sqrt n\)，就能被构造到 \(O(n\sqrt n)\)，而正确取法只要 \(O(n^{5/4})\)。原文还给了一个下界构造：取形如 \([a\sqrt n, b\sqrt n]\) 的询问点，任意两点的曼哈顿距离至少是 \(\sqrt n\)，所以哪怕改用曼哈顿最小生成树来定转移顺序，也突破不了 \(O(n\sqrt n)\)，分块排序在上界意义下已经最优。

**例题：小 Z 的袜子（[洛谷 P1494](https://www.luogu.com.cn/problem/P1494)）。** 题目要求区间内随机取两只袜子，颜色相同的概率。用 `col[k]` 记颜色 \(k\) 当前出现的次数，用 `nume` 记同色配对数。因为 \(\binom{c+1}{2}-\binom{c}{2}=c\)，加入一只颜色为 \(k\) 的袜子时 `nume += col[k]++`，删除时 `nume -= --col[k]`。答案是 \(\text{nume}/\binom{len}{2}\)，最后再约分。

**模板（奇偶化排序加安全的循环顺序）：**

```cpp
int unit;  // 块长 ≈ max(1, n / sqrt(m))
struct Q { int l, r, id;
  bool operator<(const Q& o) const {
    if (l / unit != o.l / unit) return l < o.l;
    return (l / unit) & 1 ? r < o.r : r > o.r;   // 严格比较，不能写 <= 或 >=
  }
};
long long nume; int col[N], c[N];
void add(int p) { nume += col[c[p]]++; }
void del(int p) { nume -= --col[c[p]]; }
// 主循环，初值 l = 1, r = 0（表示空区间）
for (auto& q : qs) {
  while (l > q.l) add(--l);   // 先扩张
  while (r < q.r) add(++r);
  while (l < q.l) del(l++);   // 再收缩
  while (r > q.r) del(r--);
  ans[q.id] = nume;  // 分母取 (len)*(len-1)/2，再做 gcd 约分
}
```

**复杂度与坑：**
1. 四个 while 的顺序不能随便换。原文逐个枚举了 24 种排列，只有 6 种正确。最稳妥的写法是先扩张（`l--`、`r++`）再收缩（`l++`、`r--`），这样任何时刻都满足 \(l \le r+1\)，不会出现某个元素的加入次数为负。如果你用 `set` 之类维护区间，顺序错了就会删到不存在的元素。
2. 奇偶化排序：奇数块里 \(r\) 升序，偶数块里 \(r\) 降序，让 \(r\) 指针在回程顺路处理下一块，原文说一般能快 30% 左右。比较器必须是严格弱序，同一块内 \(r\) 相等时不能两边都返回 true，否则 `sort` 可能运行错误。压行写法要专门判一下 `r == x.r`。
3. 块长按 \(n/\sqrt m\) 取，不要无脑用 \(\sqrt n\)。
4. 莫队的平均每次转移代价会随 \(m\) 增大而减小。它适合询问多、只能离线、增量 \(O(1)\) 的场景；如果增量做不到 \(O(1)\)，比如要带一个 log，就要掂量 \(O(n\sqrt m \log n)\) 能不能接受。

**原文：** [OI Wiki · 普通莫队算法](https://oi-wiki.org/misc/mo-algo/)。明天建议接着讲带修莫队。

## 19. 2026-11-01 · 带修莫队（算法，接昨天的普通莫队）

**每日讲解 · 带修莫队（算法，接昨天的普通莫队）**

**用途：** 离线处理「单点修改 + 区间查询」的混合操作，且查询只能 O(1) 增删一个元素（比如区间颜色种类数）、线段树又不好维护时用。总复杂度 \( O(n^{5/3}) \)。

**核心思想：** 普通莫队把询问看成平面上的点 \( (l, r) \)，按某种顺序走一遍。带修莫队再加一维时间 \( t \)，表示「这次询问之前做过几次修改」，所以每个询问变成 \( (l, r, t) \)。指针在三个方向上都能 O(1) 移动：\( l \pm 1 \)、\( r \pm 1 \)、\( t \pm 1 \)。其中 \( t+1 \) 是把第 \( t+1 \) 次修改加上，\( t-1 \) 是把第 \( t \) 次修改撤销。

举个例子：序列 `[1,2,1]`，第 1 次修改把 a[2] 改成 1，有个询问「修改 1 次后 [1,3] 的种类数」。处理到它时，先把 l、r 移到 [1,3]（此时 cur=2），再把时间推到 1。因为位置 2 在 [l,r] 内，要删掉颜色 2、加上颜色 1，于是 cur=1。

**排序（关键）：** 块长取 \( n^{2/3} \)，一共 \( n^{1/3} \) 块。第一关键字是 l 所在块，第二关键字是 **r 所在块**（注意不是 r 本身），第三关键字是 t。

原文说明了为什么 r 也要分块：如果 r 不分块、直接按 r 排序，同一组里的时间就是乱的，每个询问时间指针要跑 \( O(t) \)；如果 r 也乱序，每个询问 r 要跑 \( O(n) \)。两种都不行。分块后，同一个 (l 块, r 块) 组里，l 和 r 每次只动 \( O(s) \)，t 单调递增，整组合计 \( O(t) \)。总代价是 \( ms + (n/s)^2 t \)，对 s 求导得最优块长 \( s \approx n^{2/3} t^{1/3} / m^{1/3} \)，复杂度为 \( O(n^{2/3} m^{2/3} t^{1/3}) \)。n、m、t 同阶时就是 \( O(n^{5/3}) \)，实际写代码直接用 \( n^{2/3} \)。

**模板（洛谷 P1903 数颜色，按 OI Wiki 参考代码整理）：**

```cpp
struct Q { int id, t, l, r; } q[N];
struct M { int p, x; } md[N];   // 第 i 次修改：a[p] 改为 x
int S;                          // S = pow(n, 2.0/3)
bool cmp(const Q& a, const Q& b) {
  if (a.l / S != b.l / S) return a.l < b.l;
  if (a.r / S != b.r / S) return a.r < b.r;
  return a.t < b.t;
}
void add(int x){ if(!cnt[x]++) ++cur; }
void del(int x){ if(!--cnt[x]) --cur; }
void apply(int k, int L, int R) {      // 施加或撤销都调用它
  int p = md[k].p;
  if (L <= p && p <= R) { del(a[p]); add(md[k].x); }
  swap(a[p], md[k].x);                  // 精髓：交换后，再调用一次就是撤销
}
// 主循环
int L = 1, R = 0, T = 0;
for (auto& e : q) {
  while (L > e.l) add(a[--L]);
  while (R < e.r) add(a[++R]);
  while (L < e.l) del(a[L++]);
  while (R > e.r) del(a[R--]);
  while (T < e.t) apply(++T, L, R);
  while (T > e.t) apply(T--, L, R);
  ans[e.id] = cur;
}
```

读入时，遇到修改就 `md[++tc] = {p, x}`；遇到询问就记下当前 `t = tc`。

**复杂度与坑：**
- **swap 技巧是整份代码的灵魂。** 修改记录里存的是「要换进去的值」，施加之后它就变成了「被换出来的旧值」，所以同一个函数调用两次正好抵消。这样不用单独存旧值，也不怕重复修改同一个位置。
- **修改在区间外也必须 swap**，只是不更新答案。漏掉这一步，后面 r 扩展到这个位置时会读到错误的值。
- **先扩张再收缩**（先 add 后 del），保证中途不会出现 L > R+1 的非法区间。时间维放在 l、r 之后调整就行，因为 apply 判断的是当前的 [L, R]。
- **块长别抄成 \( \sqrt{n} \)。** 那样时间维会退化成每组 \( O(t) \)、总共 \( O(nt/\sqrt{n} \cdot \ldots) \)，会被卡。修改很少时（t 远小于 n），可以按公式 \( n^{2/3} t^{1/3} / m^{1/3} \) 调小块长，t=0 时就退化成普通莫队。
- 值域大要先离散化（**注意修改里的值也要一起离散化**），cnt 数组按值域开。
- 只支持单点修改。区间修改一般就不适合莫队了。

[原文：OI Wiki 带修莫队](https://oi-wiki.org/misc/modifiable-mo-algo/) ・ [例题 P1903](https://www.luogu.com.cn/problem/P1903)

## 20. 2026-11-02 · 回滚莫队（只增不删）　类型：算法（离线区间查询）

**每日 OI Wiki · 回滚莫队（只增不删）**　类型：算法（离线区间查询）

**一句话用途**：区间答案「加一个元素好维护、删一个元素没法维护」时（比如区间最大值、区间众数的出现次数），用回滚莫队，只做加法，删除这一步用撤销代替，复杂度仍是 \( O(n\sqrt m) \)。

**核心思想**：拿原文的例题 [JOISC 2014 历史研究](https://loj.ac/problem/2874) 来说，要求区间里 \( \max_x x \cdot cnt_x \)。往区间里加一个数时，新答案只可能是刚加进来那个数的重要度，取一次 max 就行；可删掉一个数之后最大值换成了谁，没法 \( O(1) \) 知道。所以把询问按左端点所在的块分组。同一组里，右端点从块的右边界往右单调扩展，只加不删；左端点每次从「块右边界加一」临时往左扩展，回答完再撤销。撤销只把 cnt 减回去，答案直接用扩展左端点之前的快照 `tmp = Ans` 恢复，所以根本不需要「带答案维护的删除」。

**怎么做**：
1. 分块，询问按（左端点所在块升序，右端点升序）排序。
2. 遇到新的一块 B 时，把莫队区间重置成空区间 \([R_B+1, R_B]\)，并令 `Ans = 0`。
3. 左右端点在同一块里的询问，直接暴力扫一遍，代价 \( O(b) \)，用一个独立的计数数组，扫完清掉。
4. 其他询问：右端点扩展到 Q.r，期间更新 Ans；记下 `tmp = Ans`，左端点从 \( R_B+1 \) 扩展到 Q.l，期间更新 tmp；记录答案；再把左边加进来的元素撤销（只做 `--cnt`）。

```cpp
// 跨块询问的主循环（据 OI Wiki 参考代码整理）
if (pos[q.l] != last_block) {           // 进入新块：清空区间
  while (r > R[pos[q.l]]) --cnt[x[r--]];
  while (l < R[pos[q.l]] + 1) --cnt[x[l++]];
  Ans = 0; last_block = pos[q.l];
}
while (r < q.r) { ++r; ++cnt[x[r]]; Ans = max(Ans, 1LL*cnt[x[r]]*t[x[r]]); }
int _l = l; ll tmp = Ans;                // 快照
while (_l > q.l) { --_l; ++cnt[x[_l]]; tmp = max(tmp, 1LL*cnt[x[_l]]*t[x[_l]]); }
ans[q.id] = tmp;
while (_l < l) --cnt[x[_l++]];           // 回滚：只还原计数
```

**复杂度**：块长记为 b。同一块内的询问暴力做，每个 \( O(b) \)。左端点在同一块的那组询问，右端点单调递增，总移动 \( O(n) \)，一共 \( n/b \) 组；左端点每次最多移动 b。合起来是 \( O(mb + n^2/b) \)，取 \( b = n/\sqrt m \) 时得到 \( O(n\sqrt m) \)。

**坑**：
- 这里不能用奇偶块交替排序优化。同一块里右端点必须单调递增，否则右端点就得删除。
- 同块询问一定要用独立的计数数组（参考代码里叫 `__cnt`），扫完马上清零，不然会把主区间的 cnt 搞乱。
- 参考代码一开始 `l=1, r=0`，进入第一块时会对没加过的元素做 `--cnt`，cnt 暂时变成负数，等右端点扫过来又会补回 0。这样做是对的，因为 cnt 始终等于区间 \([l,r]\) 带符号的计数，但读代码时容易看懵。更直观的写法是换块时直接清空 cnt。
- 值域大的话要先离散化，乘法用 `long long`。
- 只删不加的版本（比如区间 mex），原文只说实现上「有一点区别」，没有展开。我的理解（推断，不是原文内容）：每块的初始区间设成 \([L_B, n]\)，右端点按降序处理、往左收缩，左端点从 \( L_B \) 往右删，删完再回滚。

**原文**：[OI Wiki · 回滚莫队](https://oi-wiki.org/misc/rollback-mo-algo/)

## 21. 2026-11-03 · 树上莫队（算法）

**每日讲解 · 树上莫队（算法）**

用途：把「静态/带修的树上路径询问」（如路径上不同颜色数、路径上颜色贡献和）离线后用莫队做到大约 \(O(n\sqrt q)\)，前提是加/删一个点的贡献能 O(1) 更新。

**核心思想：括号序把路径压成区间。** DFS 进入 x 记一次、离开 x 再记一次，序列长 2n，记 st[x]、ed[x]。对路径 u→v（设 st[u] ≤ st[v]）：若 LCA=u，取区间 [st[u], st[v]]；否则取 [ed[u], st[v]]。区间里路径上的点恰好出现 1 次，不在路径上的点出现 0 或 2 次；第二种情况下 LCA 出现 0 次，要单独补上。所以莫队指针每扫到一个点都不分加删，只做「翻转」：vis[x]^=1，按翻转后的状态决定加还是减贡献。

小例子：链 1-2-3 加 1-4，括号序为 1 2 3 3 2 4 4 1。问 3→4：st[3]=3 < st[4]=6，LCA=1≠3，取 [ed[3], st[4]]=[4,6]，即 3 2 4，正好是去掉 LCA 1 的路径，询问时再临时翻转一次 1。

**模板（路径不同颜色数，C++）**
```cpp
void dfs(int u,int p){ ord[st[u]=++tim]=u;
  for(int v:g[u]) if(v!=p){ dep[v]=dep[u]+1; fa[v][0]=u; dfs(v,u);}
  ord[ed[u]=++tim]=u; }
// 建询问
if(st[u]>st[v]) swap(u,v); int w=lca(u,v);
q[i]= (w==u) ? Q{st[u],st[v],0,i} : Q{ed[u],st[v],w,i};
// 块长按序列长 2n 取：B = sqrt(2n)；排序同普通莫队（可奇偶优化）
void flip(int x){
  if(vis[x]){ if(--cnt[c[x]]==0) cur--; }
  else      { if(cnt[c[x]]++==0) cur++; }
  vis[x]^=1; }
int L=1,R=0;
for(auto&e:q){
  while(L>e.l) flip(ord[--L]); while(R<e.r) flip(ord[++R]);
  while(L<e.l) flip(ord[L++]); while(R>e.r) flip(ord[R--]);
  if(e.lca) flip(e.lca); ans[e.id]=cur; if(e.lca) flip(e.lca); }
```
带修版本照搬带修莫队，再加时间维，块长取 \((2n)^{2/3}\)。修改点 x 的颜色时，若 vis[x]=1，要先 flip 移出、改色、再 flip 加回，否则只改颜色。原文例题是「WC2013 糖果公园」，贡献为 \(val_c\cdot w_{cnt_c}\)，同样 O(1) 增量。

**真·树上莫队（原文第二部分）：** 不转成序列，而用「王室联邦」式分块，DFS 时用栈收集，攒满 step 个就切一块，让同块内点的距离不超过块长。询问 (x,y) 按 (bl[x], bl[y], t) 排序，指针沿树走：move(x,y) 翻转两点间路径上除 LCA 外的所有点。LCA 始终不标记，询问时临时翻转再撤回，因为两个指针同向移动时 LCA 会被翻两次互相抵消。复杂度是 x 指针总移动 n·unit 加上 y 指针 n²/unit，在根号处最优；带修时块长取 \(n^{0.6}\) 左右。实战中括号序版更好写，一般首选它。

**复杂度与坑**
- 所有数组（ord、分块 pos）要开 2n，块长也按 2n 算。
- st[u] > st[v] 先 swap，判断 LCA 用的是 u，不是区间端点。
- LCA 的临时翻转必须撤回，否则会污染后续询问；原文第一份代码直接用 id[L]、id[R] 求 LCA 再判断，效果相同，但把 LCA 存在询问里更稳。
- 翻转语义下，「加」和「删」由 vis 决定，所以四个 while 不再区分 add 和del，这一点与普通莫队不同，也是最容易写错的地方。
- 求 LCA 用倍增或树剖都行，每个询问多付 O(log n)。

原文：[OI Wiki · 树上莫队](https://oi-wiki.org/misc/mo-algo-on-tree/)。下一课预告：莫队二次离线。

## 22. 2026-11-04 · 莫队二次离线（算法 · 莫队系列第 5 篇）

**莫队二次离线**（算法 · 莫队系列第 5 篇）

**一句话用途**：普通莫队要求每次移动端点是 \(O(1)\)。如果单次转移要 \(O(\log n)\)（比如每次都要问「区间里比 x 大的数有几个」），复杂度就会变成 \(O(n\sqrt m\log n)\)，调块长也救不回来。只要这次转移的贡献能对区间做差分，就可以把转移本身再离线一次，交给扫描线批量算。

**核心思想**

记 \(f(x,l,r)\) 为 \(x\) 对区间 \([l,r]\) 的贡献。右端点从 \([l,r]\) 扩到 \([l,r+1]\) 时，要的是 \(f(a_{r+1},l,r)\)。能差分的话，它可以拆成 \(f(a_{r+1},1,r)-f(a_{r+1},1,l-1)\)：

- 第一项的形式是「\(x\) 对 \([1,x-1]\) 的贡献」，每个位置只有一个值，用树状数组 \(O(n\log n)\) 预处理就行。
- 第二项是「\(x\) 对某个前缀 \([1,p]\) 的贡献」，挂到 \(p=l-1\) 上。最后从左到右扫一遍前缀，边插入边回答。

例题是 [P5047 区间逆序对](https://www.luogu.com.cn/problem/P5047)。设 \(f(x,r)\) 为 \([1,r]\) 里比 \(a_x\) 大的数的个数，\(g(x,r)\) 为比 \(a_x\) 小的个数，四个方向的增量分别是：

- 右扩 \(r\to r+1\)：\(f(r+1,r)-f(r+1,l-1)\)
- 右缩 \(r\to r-1\)：\(-f(r,r-1)+f(r,l-1)\)
- 左扩 \(l\to l-1\)：\(g(l-1,r)-g(l-1,l-2)\)
- 左缩 \(l\to l+1\)：\(-g(l,r)+g(l,l-1)\)

带 \(x,x-1\) 的项都能预处理，剩下那项挂到另一端的前缀上。

**怎么做（关键骨架，参照 OI Wiki 示例代码）**

1. 先离散化，再用树状数组或值域分块预处理两个数组：`p1[i]` 是 \([1,i-1]\) 里比 \(a_i\) 小的个数，`p2[i]` 是比它大的个数。
2. 照常跑莫队。每次端点在 `while` 里移动时，只把预处理项累加到 `q[i].ans`。同时把这一整段移动打包成一条记录，挂到另一端的前缀位置上，不要逐步存：

```cpp
if (R < r) v[L - 1].push_back({R + 1, r, i, -1, 1}); // 区间 [R+1,r] 在前缀 L-1 上查“比我大”，系数 -1
while (R < r) { ++R; q[i].ans += p2[R]; }
if (L > l) v[R].push_back({l, L - 1, i, 1, 0});      // 在前缀 R 上查“比我小”，系数 +1
while (L > l) { --L; q[i].ans -= p1[L]; }
// 缩端点同理，符号反过来
```

3. 扫描线：`for i = 1..n`，先 `mdf(a[i])` 把 \(a_i\) 加进集合，再遍历 `v[i]` 里的每条记录，对段内每个 \(k\) 调 `qry`，乘上系数后累加到对应询问上。
4. **关键一步**：第 2、3 步算出来的都是相邻两个询问之间的「变化量」。要按莫队排序后的顺序 `q[i].ans += q[i-1].ans` 做一遍前缀和，然后才能按 id 写回答案。

**为什么第二次离线用值域分块，而不是树状数组**

扫描线阶段一共只有 \(O(n)\) 次插入，但有 \(O(n\sqrt m)\) 次查询，两边差得很多。所以要选插入 \(O(\sqrt n)\)、查询 \(O(1)\) 的值域分块：块间前缀计数 `b1` 加块内前缀计数 `b2`，查询时 `b1[bl[x]-1] + b2[x]`。这样总复杂度是 \(O(n\sqrt m+n\sqrt n)\)。换成树状数组的话，查询每次多一个 \(\log\)，前面就白优化了。这就是「根号平衡」：哪边操作次数多，就让哪边变便宜。

**复杂度与坑**

- 时间 \(O(n\sqrt m+n\sqrt n)\)。空间 \(O(n+m)\)，因为每次移动只存一个段，总共 \(O(m)\) 条记录。逐步存的话是 \(O(n\sqrt m)\)，会爆内存。
- 前缀边界容易错一位。左扩时，\(g(l-1,l-2)\) 在代码里对应 `p1[L]`：用的是严格小于，\([1,L-1]\) 和 \([1,L]\) 的计数相同，所以直接用。挂记录的位置是 `v[R]` 还是 `v[L-1]`，要和移动之前的端点值对应，所以 push 一定要写在 `while` 之前。
- `v[0]` 对应空前缀，扫描线从 1 开始即可，不用处理。
- 忘了最后那遍前缀和，是最常见的 WA。
- 能不能用二次离线，要看贡献能否对区间差分（满足可减性）。区间 mex、区间众数这类不可减的信息不行，应该回去用回滚莫队。
- 第二道例题 [P5501 来者不拒，去者不追](https://www.luogu.com.cn/problem/P5501) 是同一个套路：同时维护「比 \(a_x\) 大的数之和」和「比 \(a_x\) 大的个数」，两个都能差分，同样用值域分块。

**和前几篇的关系**：普通莫队要求 \(O(1)\) 转移。带修莫队多了一维时间。回滚莫队解决「只能加、不能删」。二次离线解决「转移太贵但可差分」。树上莫队是把树压成序列。下一篇建议讲 CDQ 分治，它也是离线换复杂度的思路。

原文：[OI Wiki · 莫队二次离线](https://oi-wiki.org/misc/mo-algo-secondary-offline/)

## 23. 2026-11-05 · CDQ 分治（算法／分治思想）

**每日讲解 · CDQ 分治（算法／分治思想）**

**一句话用途：** 把序列（或时间轴）对半劈开，每一层只算「左半对右半」的贡献，从而把三维偏序、带修改的二维数点、1D/1D DP 这类 \(O(n^2)\) 的点对关系降到 \(O(n\log^2 n)\)，而且只需要离线处理，不用写树套树。

**核心思想。** `solve(l,r)` 负责区间内的所有点对 \((i,j)\)，这些点对分成三类：两个点都在左半、都在右半，或者跨过 mid。前两类递归下去处理，当前层只处理跨 mid 的那一类。关键在于，跨 mid 的点对天然满足「左边的下标小于右边」，所以一维约束直接被分治「吃掉」了。剩下两维的处理方法是：对一维排序，双指针扫描，另一维交给树状数组（Fenwick tree）。

以三维偏序为例（[洛谷 P3810](https://www.luogu.com.cn/problem/P3810)），要统计满足 \(a_j\le a_i, b_j\le b_i, c_j\le c_i\) 的点对。先整体按 \(a\) 排序；在每一层里，左右两半各自按 \(b\) 排序，然后对右半的每个 \(j\)，用指针把左半中所有 \(b_i\le b_j\) 的点插进树状数组（按 \(c\) 下标加 cnt），再查询前缀和 \(\le c_j\)。复杂度为 \(T(n)=2T(n/2)+O(n\log n)=O(n\log^2 n)\)。

**关键模板（摘自 OI Wiki 示例代码）：**

```cpp
// 先按 (a,b,c) 排序并把完全相同的点合并成 ue[]，cnt 记录重复个数
void CDQ(int l, int r) {
  if (l == r) return;
  int mid = (l + r) / 2;
  CDQ(l, mid); CDQ(mid + 1, r);
  sort(ue + l, ue + mid + 1, cmpB);      // 按 (b,c) 排序
  sort(ue + mid + 1, ue + r + 1, cmpB);
  int i = l;
  for (int j = mid + 1; j <= r; j++) {
    while (i <= mid && ue[i].b <= ue[j].b) BIT.Add(ue[i].c, ue[i].cnt), i++;
    ue[j].res += BIT.Ask(ue[j].c);
  }
  for (int k = l; k < i; k++) BIT.Add(ue[k].c, -ue[k].cnt);  // 只撤销插入过的点，不能 memset
}
// 答案：ue[i].res + ue[i].cnt - 1，这里 -1 是去掉自己
```

**另外两种用法：**

1. **优化 1D/1D DP。** 例如 \(dp_i = 1+\max dp_j\)，条件是 \(j<i, a_j<a_i, b_j<b_i\)（二维 LIS）。这时顺序必须是 `solve(l,mid)`，然后处理左对右的转移，最后才是 `solve(mid+1,r)`，也就是按中序遍历的顺序。这样用来转移的 \(dp_j\) 已经全部算完，不会用到半成品。每个 \(i\) 会被 \((1,i-1)\) 在线段树上拆出的 \(\log\) 个区间各更新一次，所以一个都不会漏。这里的树状数组维护的是前缀 max。例题见 [SDOI2011 拦截导弹](https://www.luogu.com.cn/problem/P2487)。
2. **把动态问题转成静态问题。** 对时间轴做分治，每层只算「左半的修改」对「右半的询问」的贡献。这时所有修改都发生在询问之前，问题就退化成静态问题，可以直接用扫描线加树状数组。例题有矩形加、矩形求和，以及 [Ynoi2016 镜中的昆虫](https://www.luogu.com.cn/problem/P4690)：区间赋值后数颜色，用 pre 数组转成二维数点，配合 ODT（用 set 维护颜色相同的连续段），每次操作只会让 pre 变化 \(O(1)\) 个。如果修改之间互相独立（比如加减），递归顺序随意；如果修改之间有依赖（比如赋值），就必须按中序顺序处理。

**复杂度与坑：**

- 一般是 \(O(n\log^2 n)\)。每层都 sort 会多带一个 log，可以改成在回溯时做归并排序，把这一层降到线性，不过树状数组那个 log 还在。
- 完全相同的点一定要先去重并记 cnt。否则相同点之间会因为左右位置不同只被统计单向，答案就偏小了。
- 清空树状数组只能撤销本层插入过的点，用 memset 的话总复杂度会变成 \(O(nk)\)。
- 第三维 \(c\) 需要先离散化，树状数组的大小取 k。
- 做 DP 优化、或者修改之间不独立的时候，跨 mid 的那一步必须夹在两次递归之间。
- 进阶变形是 [HNOI2010 城市建设](https://www.luogu.com.cn/problem/P3206)，动态维护最小生成树：在递归树上把边权设成 \(-\infty\) 的修改边强制保留并缩点，把边权设成 \(+\infty\) 后不在树里的边直接删掉，让每层的图规模变成 \(O(len)\)。这里的并查集不能用路径压缩，因为要支持回退。

原文：[OI Wiki · CDQ 分治](https://oi-wiki.org/misc/cdq-divide/)

## 24. 2026-11-06 · 整体二分 · 算法（离线）

**整体二分** · 算法（离线）

一句话用途：多次「答案可二分」的询问（典型：区间第 k 小、带修第 k 小）若各自二分会 TLE，就把所有询问捆在一起对值域分治，一层只扫一遍操作序列。

核心思想：记答案值域为 \([l,r]\)，当前还要处理的操作/询问下标为 \([L,R]\)。猜 \(mid=\lfloor(l+r)/2\rfloor\)，用树状数组（单点加、前缀和）统计每个询问区间里「\(\le mid\)」的贡献个数 \(t\)：若询问要第 \(k\) 小且 \(k\le t\)，答案在左半 \([l,mid]\)，否则 \(k\leftarrow k-t\) 丢进右半。修改也按「值 \(\le mid\) 才进 BIT」切开，左右各自递归；\(l=r\) 时该批询问答案就是 \(l\)。小例子：静态区间第 k 小，先把位置 \(p\)、值 \(x\) 与询问 \((L,R,k)\) 放进同一套分治——值 \(\le mid\) 的点 `add(p,1)`，询问看 `query(R)-query(L-1)`，再清 BIT、左右递归。

怎么做（C++ 骨架，带修区间第 k 小 / Dynamic Rankings 风格）：

```cpp
struct Opt { int x, y, k, type, id; };
// type=1 询问: [x,y] 第 k 小；type=0 修改: 位置 x，值 y，k=±1（插/擦）
Opt q[N], q1[N], q2[N];
int ans[N];
void add(int p, int x);  // BIT
int query(int p);

void solve(int l, int r, int L, int R) {
  if (l > r || L > R) return;
  if (l == r) {
    for (int i = L; i <= R; i++)
      if (q[i].type == 1) ans[q[i].id] = l;
    return;
  }
  int m = (l + r) / 2, cnt1 = 0, cnt2 = 0;
  for (int i = L; i <= R; i++) {
    if (q[i].type == 1) {
      int t = query(q[i].y) - query(q[i].x - 1);
      if (q[i].k <= t) q1[++cnt1] = q[i];
      else { q[i].k -= t; q2[++cnt2] = q[i]; }
    } else if (q[i].y <= m) {
      add(q[i].x, q[i].k); q1[++cnt1] = q[i];
    } else q2[++cnt2] = q[i];
  }
  for (int i = 1; i <= cnt1; i++)
    if (q1[i].type == 0) add(q1[i].x, -q1[i].k);  // 回滚，勿整表 clear
  for (int i = 1; i <= cnt1; i++) q[L + i - 1] = q1[i];
  for (int i = 1; i <= cnt2; i++) q[L + cnt1 + i - 1] = q2[i];
  solve(l, m, L, L + cnt1 - 1);
  solve(m + 1, r, L + cnt1, R);
}
```

适用前提（许昊然论文归纳）：答案可二分；修改对判定的贡献互相独立且与判定标准无关的常量；贡献可加、满足交换/结合律；允许离线。带修时改写成「擦旧 + 插新」，初始化当插入；操作按时间塞进全局数组，分治只重排区间 \([L,R]\)。

复杂度与坑：通常 \(O(T\log V)\)，\(T\) 为扫一遍操作并用 BIT 的代价，常见 \(O((n+q)\log n\log V)\)。坑：① 进右半必须改 \(k\)（减掉左半贡献），漏改答案偏大；② BIT 用「记下修改再加回 \(-1\)」回滚，整表清空会炸复杂度；③ 静态题可用 `pos` 追踪分治中心、按值排序后滑动载入 BIT，且**不要改询问的 \(k\)**，常数接近主席树；④ 与 CDQ 分工：整体二分啃「值域可二分 + 第 k 类」，CDQ 啃「时间/空间三维偏序」——前驱后继可「CDQ 求排名 + 整体二分求第 k」。

原文：[整体二分 - OI Wiki](https://oi-wiki.org/misc/parallel-binsearch/)

## 25. 2026-11-07 · 线段树分治（线段树与离线询问） · 算法 / 离线技巧

**线段树分治（线段树与离线询问）** · 算法 / 离线技巧

用途：信息只在某个时间段存活，要离线回答「每个时刻的信息并」；典型是把「删边 / 删点」变成「可撤销并查集 + 按存活区间挂到时间线段树上」。

核心思想：把时间轴建成线段树，把每条信息按存活区间 `[L,R]` 像区间修改一样挂到 `O(log T)` 个节点的 `vector` 里。然后从根做 DFS：进节点时把该节点上所有信息 Merge 进当前状态，到叶子时记下答案，回溯时用栈撤销。根→叶路径上挂着的，恰好是该时刻仍存活的全部信息。

小例子：边 `(u,v)` 只在时刻 `[2,5]` 存在。它会挂在覆盖 `[2,5]` 的若干节点上；分治走到时刻 3 的叶子时，路径上一定经过这些节点，边已 Merge；走到时刻 1 则不会。

怎么做（C++ 骨架）：

```cpp
vector<Object> tree[N << 2];
void update(int ql, int qr, Object obj, int i, int l, int r) {
  if (ql <= l && r <= qr) { tree[i].push_back(obj); return; }
  int mid = (l + r) >> 1;
  if (ql <= mid) update(ql, qr, obj, i << 1, l, mid);
  if (qr > mid) update(ql, qr, obj, i << 1 | 1, mid + 1, r);
}

stack<Object> sta; Object now; Object ans[N];
void solve(int i, int l, int r) {
  auto lvl = sta.size();
  for (Object x : tree[i]) { sta.push(now); now = Merge(now, x); }
  if (l == r) ans[l] = now;
  else {
    int mid = (l + r) >> 1;
    solve(i << 1, l, mid); solve(i << 1 | 1, mid + 1, r);
  }
  while (sta.size() != lvl) { now = sta.top(); sta.pop(); }
}
```

可撤销并查集：只能按秩/按大小合并，**禁止路径压缩**（否则撤销代价爆炸）。`merge` 时把改过的 `fa`/`siz` 压栈，`undo` 弹出还原。二分图判定用种类并查集（点拆成 `x` 与 `x+n`），模板题 [P5787](https://www.luogu.com.cn/problem/P5787)。

常见变形：
- 「除某种颜色外」：把颜色当时间轴，颜色 `c` 的边挂到 `[1,c-1]∪[c+1,k]`。
- 「询问经过边 `(x,y)` 的路径数」：答案 = 去掉该边后两侧连通块大小之积；把询问时刻拆成边暂时不存在的一瞬（如 [P4219 大融合](https://www.luogu.com.cn/problem/P4219)）。

复杂度与坑：总时间 `O(n log n · (T(n)+M(n)))`，空间 `O(n log n)`（每条信息复制 `O(log T)` 份）。撤销**不维持均摊**，所以并查集不能路径压缩。区间端点开闭要统一（模板常用左闭右开再映射成叶子）。某子树已判定整段时间答案相同（如已非二分图）可剪枝整段填答案，少递归。
