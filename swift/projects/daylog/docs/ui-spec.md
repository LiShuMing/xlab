# UI 设计规范 · v0.1

状态：v0.1 基线归档。经过 v0.2 多方向比较，用户选择 C；当前规范增量见 [v0.3 Studio 迭代](studio-v3.md)。本文件中的基础交互要求继续作为参考，视觉参数已由后续稿件替代。

## 1. 设计目标

打开就能写；一眼找到正在做的事；一天结束后自然形成工作记录。首屏优先给 TODO 和工作随记，AI 按需出现。

已选方向「原生极简」：中性系统表面、系统字体、蓝色强调、轻分隔线和原生侧栏。默认不显示装饰性陪伴文案，标题直称“今天 / 历史记录 / 个人日记”。不使用大面积渐变、拟物纸张和营销式标语。原型保留温暖纸感、轻松活泼作为对照，不作为默认推荐。

原生实现优先使用系统语义色和材质；浏览器中的 RGB 只用于视觉近似。macOS 窗口材质与系统版本相关，留给 SwiftUI 真机验证，不以手写模糊效果冒充系统材质。

## 2. 界面结构

### W01 今日工作页

- 建议默认 960 × 720 pt；原生窗口最小约 720 × 560 pt，支持缩放与纵向滚动。
- 左侧导航约 180 pt：今天、历史、日记、底部设置。个人日记是附加功能，原型先展示入口与排版，不代表调整原先实现优先级。
- 主内容左右留白 32–40 pt，内容最大宽度约 760 pt。顶部日期、主标题、简洁进度；不放统计仪表盘。
- 第一块“今天的重点”：一行可编辑文字，可留空。
- 第二块“今日待办”：单行输入、新增按钮、任务列表。已完成任务在列表下方，仍可撤销。
- 第三块“工作随记”：时间线和快速输入；用于记录过程，不要求整理成完整文章。
- 页尾“整理今天”：打开回顾草稿，原始工作记录仍在页面上。
- “待安排”只在存在过去未完成任务时出现，支持逐项加入今天。首版不自动搬运任务。

### W02 菜单栏面板

- 约 360 pt 宽，内容高度随任务数量变化；原生版本限制最大高度并在列表内滚动。
- 只包含今日进度、快速输入、少量任务和“打开工作日记”。展示与主窗口相同的任务状态。
- 打开后聚焦输入；Escape 关闭；点击任务标题进入主窗口编辑。
- 桌面设计稿上方的“DayLog + 进度”模拟系统菜单栏入口；打开后是局部面板，不是应用第二条导航。

### W03 历史

- 按日期列出工作记录，点击展开当日重点、当日完成项和遗留项。
- 搜索范围明确为工作内容；个人日记独立进入。
- 当日完成情况与任务当前状态分开表达；不使用当前任务状态反推历史。
- 原型演示日期展开和关键词筛选；不模拟数据库全文搜索性能。

### W04 个人日记

- 独立编辑区、日期和保存状态；默认不加入工作总结。
- 首版用纯文本或轻量 Markdown 输入，避免引入大型富文本编辑器。
- 原型只保存当前页面会话内的文字；刷新会丢弃，不能用作真实日记。

### W05 今日回顾草稿

- 点击按钮后在工作页下方展开，保留任务上下文，不强制跳到聊天界面。
- 包含“已完成”“进行中/待处理”“下一步建议”；事实来自任务，建议明确区分。
- 来源数量、重新整理、可编辑正文、采纳为工作随记。
- 真实产品在生成前展示发送范围与 Provider；无 Provider 时引导配置，不悄悄请求外部服务。
- 原型采用本地规则生成演示文字，标记“演示草稿”；不调用 LLM。采纳只影响演示数据。

### W06 设置与提醒

- 设置页包含提醒时间、工作周、日期例外、外观、登录启动、模型和导出。
- 原型仅演示早晚提醒开关和时间选择；明确写为演示状态，不弹真实权限框。
- 系统通知不自绘成正式产品 UI；后续在 macOS 验证授权、专注模式、点击路由和通知样式。

## 3. 视觉参数（建议）

| Token | 明亮 | 深色 | 用途 |
| --- | --- | --- | --- |
| paper | #FAFAFA | #242426 | 主工作区 |
| sidebar | #F0F0F2 | #1E1E20 | 导航 |
| surface | #FFFFFF | #303033 | 输入、浮层 |
| ink | #27292E | #EDEDF0 | 正文 |
| secondary | #676A73 | #B4B5BD | 辅助文字 |
| accent | #2467B2 | #96C4FF | 强调与选中 |
| accentSoft | #E8EFFA | #2B3D55 | 当前导航、重点区 |
| separator | #DEDEE4 | #46464E | 细分隔线 |

系统字体映射：SF Pro + 中文系统回退；正文 14 pt、辅助 12 pt、页面标题 28 pt，标题 medium。间距采用 4/8/12/16/24/32；输入圆角 8、内容块 12、菜单面板 14。可点击行默认至少 40 pt，舒展模式约 52 pt。强调色不承担唯一的状态表达。

页面使用浅深双套语义颜色，默认跟随系统。原型额外通过设计控件切换 A/B/C、浅深模式和列表密度，这些比较工具不进入产品。

## 4. 交互契约

| 操作 | 行为 | 异常/边界 |
| --- | --- | --- |
| 回车新增任务 | 忽略首尾空白，追加未完成项并清空输入 | 中文输入法组词时不提交；空值不新增 |
| 勾选任务 | 更新状态、进度和两处列表 | 再次点击可撤销；保存失败保留重试提示 |
| 编辑标题 | 行内编辑，失焦提交 | 空标题恢复旧值；不因布局重绘丢失输入 |
| 补充进展 | 任务详情内编辑备注 | 原型通过展开区域演示 |
| 记一笔 | 回车提交一条工作随记 | 多行编辑后续明确 Shift+Enter 规则 |
| 采纳总结 | 明确操作后添加工作随记 | 不直接覆盖原始任务和已有随记 |
| 跨日 | 切换新的 WorkDay，旧任务进入待安排 | 不自动修改昨日快照 |
| 关闭窗口 | 收起主界面，菜单栏继续工作 | 原型只展示窗口装饰，不模拟进程退出 |

可访问性：可见焦点、键盘可达、控件中文标签；进度动态变化只简洁播报。Reduce Motion 时关闭装饰动画；文本与选中状态不单靠颜色区分。

## 5. 必须补齐的原生状态

| 状态 | 展示/处理 |
| --- | --- |
| 首次使用/空列表 | 一句短提示 + 可直接输入，无强制教程 |
| 保存中/失败 | 工具栏轻提示，失败可重试，保留本地编辑缓冲 |
| 提醒未授权 | 设置页显示状态与打开系统设置入口 |
| AI 未配置/不可用 | 保留记录能力，草稿区域解释缺少的配置 |
| AI 生成中/取消/超时 | 就地显示状态，取消不改变任务 |
| 来源已变化 | 草稿标注过期，提供重新生成 |
| 删除/误操作 | 软删除或撤销入口，恢复后保留事件历史 |

这些状态是实现验收要求；v0.1 交互稿未完整模拟所有故障。

## 6. SwiftUI 对应关系

| 设计元素 | 计划实现 |
| --- | --- |
| 菜单栏及快速输入 | MenuBarExtra + window style |
| 左侧导航及主窗口 | NavigationSplitView + Window |
| 任务列表与行内编辑 | List/自定义行 + TextField + Toggle |
| 日期与历史 | DatePicker + 分组列表 |
| 个人日记/总结草稿 | TextEditor |
| 设置 | Settings scene + Form |
| 输入与键盘操作 | FocusState + Commands，避免全局捕获文字输入 |
| 数据呈现 | Observation 状态 + 应用服务，不在 View 内直接调模型 |

浏览器原型用于确认视觉和流程。字体度量、窗口材质、焦点、中文输入、滚动与真实通知必须在 SwiftUI 原型中二次验收。
