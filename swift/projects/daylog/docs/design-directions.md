# UI 方向探索 · v0.2

2026-09-18：用户认为 v0.1 过于简单，希望提供 Material 风格或更现代的设计选择。保留“简约、现代、苹果整体风格”的背景偏好，重新打开具体视觉方案的评审；尚未确定最终方向。

## 官方参考与解释

用户使用了 materialization 一词，这里将它覆盖为两种相关探索，而不是认定用户特指某个设计系统：

- **Apple Liquid Glass**：苹果的动态材质体系，导航与控制层浮在内容之上。参考 [Liquid Glass 概述](https://developer.apple.com/documentation/TechnologyOverviews/liquid-glass) 和 [Materials HIG](https://developer.apple.com/design/human-interface-guidelines/materials)。
- **Material 3 Expressive**：Google 的 Material 3 扩展，强化形状、颜色、尺寸、排版与动效的表达。参考 [Google 官方设计研究](https://design.google/library/expressive-material-design-google-research) 和 [Material 3](https://m3.material.io/)。
- **Graphite Studio**：本项目自行设计的现代专业工作台方向，不称为官方设计系统或“最新标准”。

本轮稿件不是 Apple/Google 官方组件的精确复制，尤其不将网页渐变和阴影等同于系统 Liquid Glass 的光学与动态效果。

## 三种选择

| 方向 | 信息架构 | 视觉特点 | 适合的倾向 |
| --- | --- | --- | --- |
| A · Liquid Glass 空间层次 | 悬浮侧栏、今日重点、任务与工作记录双栏 | 环境色、浅层次、高光边缘、胶囊工具栏 | 更接近现代 Mac 原生应用，安静但有质感 |
| B · Material 3 Expressive | 顶部导航、重点大卡片、组合式任务列表 | 大字号、非对称圆角、紫绿色调、鲜明形状分组 | 希望明显有趣、有识别度，愿意接受更强的视觉个性 |
| C · Graphite Studio | 窄导航、任务列表、右侧任务详情 | 精细分隔、较高信息密度、少量铜色强调 | 长时间办公、频繁更新任务进展 |

三版使用同一组 4 个任务便于比较；完成数量从复选框实时计算，不使用装饰性效率评分。形状、内容编排、导航和编辑方式都有差异。

## 已实现的设计稿交互

- 三版均可新增/完成任务、补充工作记录、切换今天/历史/日记、生成规则型演示回顾。
- A 可筛选全部/未完成；设计调整支持层次与浅深外观。
- B 可对比鲜明/克制圆角；主要动作以独立形状强调。
- C 点击任务后在右侧编辑进展，切换任务时保留本次会话的备注；设计调整支持信息密度。
- 历史是固定示例，日记是临时编辑区，不接数据库；回顾没有调用模型。
- 设计稿默认跟随宿主浅深模式，也可在设计调整面板显式切换。

## 原生实现约束

A：优先使用系统导航、工具栏与材质；玻璃效果集中在导航/控制层，任务正文保留稳定、清晰的底色。macOS 26 的材质能力与 macOS 14 基线分开处理；最终是否保持 14 兼容，待选择方向后确定。减少透明度/动态效果时应有清晰降级。

B：仍用 SwiftUI 实现形状与排版，不引入 Android/Flutter 运行时。原生窗口管理、键盘、焦点、通知遵循 macOS。自定义控件比例更高，需要更多可访问性、命中区域和动效验证。

C：用分栏与任务详情构成高效工作区；网页窄导航只是示意，原生版仍需完整的可访问标签和工具提示。宽度不足时详情变为独立页面或 sheet。

## 下一轮评审

先选整版 A/B/C，或明确混合方向，例如“A 的材质 + C 的任务详情”。确定后再细化菜单栏、编辑态、空态、提醒和 AI 草稿，不把三套界面一起作为正式产品功能维护。

建议先考虑 A；如果更重视持续写进展，可使用 A 的材质与 C 的列表/详情结构。该建议尚未获得用户确认。
