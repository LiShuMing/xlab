## 实现决策补充

- 原子保存整个版本化工作空间，先解决个人日记一致性；实体拆分与大数据优化后续进行。
- 导入的完整 LLM profile 一起存 Keychain，避免地址/密钥部分更新。
- 首版模型非流式、无自动重试、仅显式点击生成；编辑和采纳均由用户控制。
- UI 保留原生系统控件，细节可继续迭代，不再阻塞首版运行。
