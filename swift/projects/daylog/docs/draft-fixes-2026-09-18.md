## 实现与数据语义

`DayLog/App/Drafts.swift` 定义 DraftID、PendingDraft 和草稿目的。所有页面共用相同清单，过滤空白和未改变的值。任务行显示未保存标记；DraftNavigation 每次携带新请求 ID，保证重复定位同一字段仍可聚焦。

`saveDrafts` 在 Workspace 副本中应用整组输入，再经 `AppStore.commit` 校验和接受。无效提醒时间或任务 revision 冲突会使整组失败，不部分提交、不清空输入；成功后才清理对应缓冲。接受后的快照仍由 SaveQueue 后台落盘，正常退出沿用 flush 与失败保护。界面中的“保存全部”不意味着绕过现有持久化状态提示。

ExportDocument 冻结调用时的 Workspace 和遗漏数量。导出在后台编码并原子写文件；保存路径面板取消时，不撤销此前明确选择的“保存全部”。JSON schemaVersion 仍为 1；模型凭据不进入导出，工作 Markdown 继续排除私人日记。

`Core/ReviewMarkdown.swift` 提供轻量分块与行内 AttributedString；`Features/MarkdownText.swift` 提供阅读、编辑切换和折叠。移除可点击链接，不执行 HTML，不加载远程图片。原始文本仍用于编辑和存储。

本轮原生复测另外修复了两个交互问题：

- 连续导出时同步 NSSavePanel 可能出现不可保存状态。改为下一主线程循环异步 `begin`，避开 SwiftUI sheet 关闭中的同步模态调用，重新实测保存全部导出成功。
- 草稿列表内已显示的校验错误在“前往”后重复弹窗。关闭、定位或继续导出时清理已消费错误；最终构建已验证直接聚焦原输入。

## 自动回归

运行 `./scripts/check.sh`，失败返回非零退出码。仍为 CLT 下的可执行检查，不声称执行过 XCTest/UI 测试套件。

| 检查 | 数量 | 范围 |
| --- | ---: | --- |
| 核心领域 | 19 | 跨日、冲突、回顾来源、私人隔离、JSON、配置、提醒排期 |
| 保存回归 | 20 | 合并、并发、写入失败、重试、退出 flush、真实 SQLite |
| 工作流回归 | 30 | 状态撤销保留编辑、回顾输入边界、私人草稿隔离、来源变化 |
| 新增草稿与阅读回归 | 31 | 草稿保留、明确定位、统一保存原子性、导出快照、SQLite 重读、Markdown 安全格式 |
| 跨进程存储 | 4 个结果 | 普通和超过 50 MB 的工作空间，分别保存及新进程恢复 |

新增检查位于 `qa/DraftChecks.swift`，可单独运行 `./scripts/check-drafts.sh`。包含所有草稿类型统一提交、重复保存不新增记录、无效设置或旧 revision 失败后保留全部输入、纠正后重试，以及真实 SQLite 关闭重读。原有工作流检查同步验证“具体草稿列表”取代泛化错误提示。

## 原生使用场景

使用独立 Bundle ID `app.daylog.qa` 和 `--demo` 内存工作空间。未向正常日记写测试条目，未开启通知或登录项。模型验证手动读取现有配置，发送虚构工作任务；私人日记未进入模型输入，密钥未写入日志或截图。

1. 修改提醒至 10:15，切换今日再回设置，仍保留输入且有未保存计数；Cmd+S 后清除计数。
2. 在任务 A 留下进展草稿，切换到任务 B，生成回顾时准确列出 A；前往后选中 A，并聚焦原进展文本。
3. 工作随记与私人日记各留一处输入，备份显示两项及范围选择。仅导出已提交内容后保留两处输入，并显示明确遗漏提示。
4. 选择保存全部并导出，实际 JSON 含两个测试标记，未保存计数清除。[JSON 检查结果](../qa/evidence/2026-09-18-draft-fixes/backup-inspection.json) 记录两种范围的结果；两个备份来自不同的隔离演示运行，不用于比较其他状态。
5. 真实模型生成结果以阅读排版显示（截图 07）。随后人工编辑为含标题、强调、有序列表和代码块的验收文本，Cmd+S 保存、预览、采纳；今日、详情、历史均显示格式，长内容可展开/收起（截图 08—11）。
6. 无效时间 25:90 保存失败后仍可修正；最后一次补丁验证“前往”不重复弹错（截图 15）。
7. 带草稿退出可返回清单，再定位提醒字段；选择保存全部并退出，隔离进程正常结束。
8. 退出正常旧实例后启动最终 build/DayLog.app，确认“保存全部 / 查看未保存内容”菜单出现；正常工作空间仍为原有空状态。

## 保留的边界

- 草稿保留限于当前进程。未提交输入的崩溃恢复、强制终止前的持久化仍是后续工作；本轮不新增数据库草稿表。
- Markdown 是常用子集，不承诺完整 GFM 表格、嵌套列表或图片；链接显示文字，不跳转。
- 原生截图验证演示界面；持久化由隔离真实 SQLite 回归验证，二者不混为一项证据。
- 系统通知实际投递、登录启动、真实拼音组词、VoiceOver 和 macOS 14/15 仍按 TASKS.md 保留专项验收。
